If you’re interested in poster graphics, you should check out the Plakatsammlung (Poster Collection), although it seems they are in limited service these days. [http://www.museum-gestaltung.ch/en/collections/poster/](http://web.archive.org/web/20140804173631/http:/www.museum-gestaltung.ch/en/collections/poster/ "http://www.museum-gestaltung.ch/en/collections/poster/") There are some great museums and galleries in Zurich (and even more in Basel, which is an hour away). If you want some printing/type/book-historical background I highly recommend the Swiss museum of paper, type and printing, which is in Basel: [http://www.papiermuseum.ch/en/the-museum/](http://web.archive.org/web/20140804173631/http:/www.papiermuseum.ch/en/the-museum/ "http://www.papiermuseum.ch/en/the-museum/")
