[Vonness](http://web.archive.org/web/20141119054144/http:/www.fontbureau.com/fonts/Vonness) or [Venus](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/search/venus) ( [Extended](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/fonts/efscangraphic/venus-sb) version by Scangraphic) might work (or match actually if only [Venus Extended Extra Bold](http://web.archive.org/web/20141119054144/http:/typophile.com/node/41686#comment-256320) was digitized). A list of **similars to Annonce** now: [Doublewide](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/fonts/betatype/doublewide/), [Azidenz Grotesk Extended Bold](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/fonts/berthold/akzidenz-grotesk-be/), [Titling Gothic Extended/Wide Bold](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/fonts/fontbureau/titling-gothic-fb/), [Zeppelin 43/51 Bold](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/fonts/storm/zeppelin/), [Reservation Wide](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/fonts/typetrust/reservation-wide/), [Presicav](http://web.archive.org/web/20141119054144/http:/www.myfonts.com/fonts/typodermic/presicav/)
