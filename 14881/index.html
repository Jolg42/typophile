The “Country Road” logo is set in [ITC Avant Garde Gothic](http://web.archive.org/web/20051125213358/http:/www.fontshop.com/index.cfm?fuseaction=catalog.fontpackage&startrow=1&records=&currpage=1&totalrecords=3&displayfontid=EF.369.0.0&fontRendererText=COUNTRY+ROAD) — Typophile uses [Gotham](http://web.archive.org/web/20051125213358/http:/www.typography.com/catalog/gotham/index.html) as its primary sans face, although the Typophile logo used to be / is (?) set in a wide weight of [Knockout](http://web.archive.org/web/20051125213358/http:/www.typography.com/catalog/knockout/index.html).
