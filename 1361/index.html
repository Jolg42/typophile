The problem occurs when points from two different paths are directly on top of each other and one of the paths is a counter (like the inside of an "o"). The method shown in the old Atomic Media tutorial (no longer available) was to use Fontographer's Change Weight command to make the characters slightly bolder, then use the Remove Overlap command. This causes the outside of the glyph to get larger and the inside smaller, neatly moving the offending points away from each other. There are other ways to do it, but the main thing is to avoid overlapping points. FWIW, the method in the tutorial you linked to works too, but the "cut" would be visible in some uses (if you used it large, for example).
