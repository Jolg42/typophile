VHS tape boxes. I used to have a huge number of these, including this brand. Looks like a photo compressed font. There are normal width substitutes that might pass for \_HQ\_, such as Century Oldstyle [http://www.myfonts.com/fonts/mti/century-os-mt/](http://web.archive.org/web/20150317080452/http:/www.myfonts.com/fonts/mti/century-os-mt/ "http://www.myfonts.com/fonts/mti/century-os-mt/") but I didn't spot anything that world work perfectly as a digital substitute for the compressed text \_HQ HIGH QUALITY TAPE\_. The closest I was able to find out of the box is Georg Trump's Mauritius Medium Condensed as digitized by Canada Type ![](http://web.archive.org/web/20150317080452im_/http:/typophile.com/files/MauritiusMediumCondensedInUse_3834.gif) [http://www.myfonts.com/fonts/canadatype/mauritius/](http://web.archive.org/web/20150317080452/http:/www.myfonts.com/fonts/canadatype/mauritius/ "http://www.myfonts.com/fonts/canadatype/mauritius/") An alternative, Monotype Clarendon® Condensed ![](http://web.archive.org/web/20150317080452im_/http:/typophile.com/files/MonotypeClarendonCondensedInUse_5727.jpg) [http://www.fonts.com/font/monotype/monotype-clarendon/condensed](http://web.archive.org/web/20150317080452/http:/www.fonts.com/font/monotype/monotype-clarendon/condensed "http://www.fonts.com/font/monotype/monotype-clarendon/condensed") Don

edited: You can get a lot closer by taking a bold weight of a font with similar letterforms and compressing the width to perhaps 85% This one is News 706 Bold ![](http://web.archive.org/web/20150317080452im_/http:/typophile.com/files/News706BoldInUseWidth85pct_4479.jpg) [http://www.myfonts.com/fonts/bitstream/news-706/](http://web.archive.org/web/20150317080452/http:/www.myfonts.com/fonts/bitstream/news-706/ "http://www.myfonts.com/fonts/bitstream/news-706/") If you want to get a pretty good match you could edit the tail on Q and anything else that you think is out of place. A runner up is Harriet Text Bold ![](http://web.archive.org/web/20150317080452im_/http:/typophile.com/files/HarrietTextBoldInUseWidth85pct_4342.jpg) [http://www.myfonts.com/fonts/okay-type/harriet/](http://web.archive.org/web/20150317080452/http:/www.myfonts.com/fonts/okay-type/harriet/ "http://www.myfonts.com/fonts/okay-type/harriet/") Same comments on editing. Some fonts have a weight heavier than bold, which might give a better match for weight when the width is compressed to perhaps 85% This one is Ingeborg Heavy. ![](http://web.archive.org/web/20150317080452im_/http:/typophile.com/files/IngeborgHeavyInUseWidth85pct_3698.jpg) [http://www.myfonts.com/fonts/typejockeys/ingeborg/](http://web.archive.org/web/20150317080452/http:/www.myfonts.com/fonts/typejockeys/ingeborg/ "http://www.myfonts.com/fonts/typejockeys/ingeborg/") Same comments on editing. Don
