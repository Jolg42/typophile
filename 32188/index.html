I have used it as a Type 1 font. Unless it has been substantially redrawn since the late 1990s, it won't work at small sizes -- say less than 20-point -- for offset printing. Rich Hendel (author of <cite>On Book Design</cite>) uses it some for display, and it works quite well. But leading in display type depends of both the size of the type & number of words involved, as well as other design factors.
