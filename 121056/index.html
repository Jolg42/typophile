Confirming Bookman. Quoting MF description text: "Bookmania (2011) is a revival of Bookman Oldstyle (1901) and the Bookmans of the 1960s, but with all the features you would expect in a modern digital font family." Don't know any other version of Bookman available with such an amount of alternate glyphs: / [B](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/547), / [k](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/1653), / [r](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/1789), / [y](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/1965) and / [A](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/279) for your sample Baseline is also Bookman. My suggestion would probably to keep Bookmania scaling it to match the lettering using / [K](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/775), / [N](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/917), / [P](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/1041) and / [R](http://web.archive.org/web/20150317053658/http:/www.myfonts.com/fonts/marksimonson/bookmania/semibold/glyphs.html#glyphs/519883/1050) alternate glyphs.
