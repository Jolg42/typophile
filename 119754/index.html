\_MASTERS OF SEX\_ is a fairly close match to the similarly named "Lust" [https://www.myfonts.com/fonts/positype/lust/](http://web.archive.org/web/20141124153055/https:/www.myfonts.com/fonts/positype/lust/ "https://www.myfonts.com/fonts/positype/lust/") \_R\_ seems pretty well spot on. Use the leg from \_R\_ for the strokes on \_M\_ and \_A\_. Use the Didone version of Lust. I suspect that \_MASTERS OF SEX\_ is not a specific font as such, but rather is yet another attempt to make a sexy set of Didone letters. Don
