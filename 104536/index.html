Seems to me that the Dempster's wordmark, U.S. trademarked in 1992, is very close to Goudy Heavyface Condensed: ![](http://web.archive.org/web/20140828235822im_/http:/typophile.com/files/GoudyHeavyFaceCondensed_Dempsters_5276.jpg) I used the Berthold version for the comparison but was unable to find a current seller. So here is a link to the [Bitsteam version](http://web.archive.org/web/20140828235822/http:/www.fonts.com/font/bitstream/goudy-heavyface/condensed). If Goudy Heavyface Condensed was used as the basis for the wordmark, some further horizontal squeeze was done and some relatively minor modifications were made to the letters, except for s, which grew a long tail, and p which now has an old-style bottom terminal. The comma is clipped into a stubby tear shape. Don
