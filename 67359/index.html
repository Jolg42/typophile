here is a technical answer. The technique is the same as the ligature, using the FEATURE. Of course you need new "generated glyph" for the subtitution (eg: "f\_f\_l", "T\_h"). FEATURE for ligature is LIGA for Discretionary ligature is DLIG for Contextual ligature is CALT etc. Wiki can help: [http://en.wikipedia.org/wiki/OpenType\_feature\_tag\_list](http://web.archive.org/web/20150311183618/http:/en.wikipedia.org/wiki/OpenType_feature_tag_list "http://en.wikipedia.org/wiki/OpenType\_feature\_tag\_list") here is some example: feature liga { sub f f b by f\_f\_b; sub f f h by f\_f\_h; sub f f i by ffi; } liga; feature dlig { sub T H by T\_H; sub T T by T\_T; sub T h by T\_h; sub s p by s\_p; sub s t by s\_t; } dlig; feature calt { sub T H E by T\_H\_E; } calt;
