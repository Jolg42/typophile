3 Comments

Looks like they've started from Saturday's own corporate typeface [Industria](http://web.archive.org/web/20140805095649/http:/www.typophile.com/node/77367) and tweaked it. It looks to mix influences from [Big Caslon](http://web.archive.org/web/20140805095649/http:/www.fonts.com/font/carter-and-cone/big-caslon) (former font on which [Industria is based](http://web.archive.org/web/20140805095649/http:/www.typophile.com/node/77367#comment-444953)) and [Tiffany](http://web.archive.org/web/20140805095649/http:/www.myfonts.com/fonts/itc/tiffany) (mainly on / [M](http://web.archive.org/web/20140805095649/http:/www.myfonts.com/fonts/itc/tiffany/std/glyphs.html#glyphs/538425/46) and / [N](http://web.archive.org/web/20140805095649/http:/www.myfonts.com/fonts/itc/tiffany/std/glyphs.html#glyphs/538425/47))/Big Caslon /A top. Don't know too much about [Patrician](http://web.archive.org/web/20140805095649/http:/www.myfonts.com/fonts/scriptorium/patrician) part of it looks very close to (Big) Caslon... There are also some [rip-off accusations on some Scriptorium David Nalle's fonts](http://web.archive.org/web/20140805095649/http:/typophile.com/node/51142?page=1#comment-310076) so better avoid Patrician...
