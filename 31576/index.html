\> _When using the auto hint macro is it normal to get along list of corrections in the output window._ Yes, if you are running in "Verbose Mode". To change the Autohint preferences, hold the Ctrl key while you click on the Play button. ![](http://web.archive.org/web/20131014050156im_/http:/typophile.com/files/AH_prefs_4876.png) \> _Are these corrections the macro has made, or are these corrections I need to make._ The macro won't make any changes to the outlines, unless you allow it (not recommended). You can think of it as a report of suggestions. For example, seems like you've setup a standard stem with the value 57. When the autohint macro finds outlines where the stems are not exactly that value, it flags a near miss.
