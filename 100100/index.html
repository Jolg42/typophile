Hi Yael, #1 looks like **[Brushstroke Plain](http://web.archive.org/web/20130324052046/http:/www.fontsquirrel.com/fonts/Brushstroke-Plain)** free font by Kevin Willis (1992) Note though that there is another quite similar font called **Pennello Becker** (Copyright 1999 Data Becker) so, I 'm not sure if Brushstroke Plain is the actual original design. #2 must be a handwritten font called **Maria** but I have no more data about it (Designer, Foundry, License etc) and I have not found any legitimate source to acquire it, therefore I advise to check twice and be extra careful if you want to license/use the font in any commercial project.
