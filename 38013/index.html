The ruler on the tool bar, next to the knife, becomes active when you open a glyph window. Also Alt + 4 turns it on. On my PC control + alt + shift changes the arrow to the measuring tool while you hold it down. The only problem with that is that it will sometimes switch the keyboard to another language, as alt + shift changes the keyboard to another language on a PC. As you are on a Mac it's probably a bit different.

Anonymous @ 12 Oct 2007 — 10:20am
Nick, The measurement line sometimes goes far away to the space on both platforms. To make it visible again use the Python script below. Open your font, open the Edit Macro panel, put this small program there and click on the Run Macro button. fl.font.measurement = 400 fl.UpdateFont() These two strings will set the Measurement line for the current font to 400 units. Regards, Johnych
