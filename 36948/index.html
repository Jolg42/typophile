Anonymous @ 10.Sep.2007 2.57pm
XeTeX is definitely the easiest route to using more typefaces, but beware that not every typeface has all the math support that you might need. See for example, [Stephen Hartke’s article in the PracTeX Journal](http://web.archive.org/web/20080503074405/http:/www.tug.org/pracjourn/2006-1/hartke/) on math fonts. For regular (PDF)LaTeX, see the excellent [Font Installation Guide](ftp://tug.ctan.org/pub/tex-archive/info/Type1fonts/fontinstallationguide/fontinstallationguide.pdf) by Philip Lehmann. Also, there are several articles about font installation in the PracTeX Journal.
Anonymous @ 10.Sep.2007 5.03pm
In addition to the Font Installation Guide, the LCDF typetools are a very easy way to install OpenType fonts into LaTeX. There is an automatic mode that is almost automatic. I think there’s one configuration—the updating updmap if I remember correctly—that’s not automatic. These comments are based on my experience running LaTeX under Linux. I haven’t tried doing this on Windows. Edit: OK, I hate to be one of those Linux-using, command-line loving people who throw the word “easy” around indiscriminantly. After looking up the scripts I wrote to install fonts with otftotfm, I’d say the correct phrase is “easier than it used to be.” And it’s writing of the .fd files for use with LaTeX that’s not automatic. There appears to be a script called [otfinst](http://web.archive.org/web/20080503074405/http:/www.ctan.org/tex-archive/fonts/utilities/otfinst/) that automates even more of the process.
