There is no UI for it (so you will have to use some Python script every time you want to hide or show outlines), but that is bit 0x00000200 or the options.PaintStyleEx: to hide outline: options.PaintStyleEx = options.PaintStyleEx | 0x00000200 to show outline: options.PaintStyleEx = options.PaintStyleEx & ~0x00000200 This is a full list of “constants” to control apperance in the GW (all changes should be made before GW is open, use on your own risk, no additional description, no support provided, no questions answered) #define psNODES 0x00000001 #define psCONTROLVECTORS 0x00000002 #define psALIGNMENT 0x00000004 #define psNOCLOSEPATHS 0x00000008 #define psSELECTION 0x00000010 #define psEMPTYVECTORS 0x00000020 #define psCLOSEPATHARROWS 0x00000040 #define psIMAGE 0x00000080 #define psPREVIEW 0x00000100 #define psNOBODY 0x00000200 #define psNOCOMPOSITES 0x00000400 #define psGLYPHMETRICS 0x00000800 #define psFONTMETRICS 0x00001000 #define psTEMPLATE 0x00002000 #define psGROUPS 0x00004000 #define psNEIGHBOURS 0x00008000 #define psHINTS 0x00010000 #define psREPLACE 0x00020000 #define psGUIDES 0x00040000 #define psGRID 0x00080000 #define psMASK 0x00100000 #define psBLUES 0x00200000 #define psFONTAUDIT 0x00400000 #define psOPENTYPE 0x00800000 #define psNOPAINT 0x01000000 #define psNOLINKS 0x02000000 #define psPOSITIONS 0x04000000 #define psNOCOLORCLOSEPATH 0x08000000 #define psOPENCONTOURS 0x10000000 #define psCONTOURDIRECTION 0x20000000 #define psNODIGITS 0x40000000 #define psNOCONTOUR 0x80000000 :-)

Anonymous @ 8.Sep.2007 12.47pm
Sounds good! One thing I’d like to point out though, and I hate to seem like I’m trying to break the record for sounding like a broken record, but...The best way to preview glyphs while editing the outline should have two pair-o-modes; one where the user has turned off the nodes, in which case they should never appear, and one where the nodes are on, and they don’t disappear. The other mode pair being that the contour should fill with and without showing itself. So what’s the broken record? FOG had this right. One turned off the nodes and could edit them “sight unseen”, i.e. the nodes never appeared when “turned off” even when selected. Later, PvB’s very first customization of FOG was a cmmd key to show a filled glyph in the glyph window. We felt this last little thing was the completion of a perfect letter drawing interface. With the nodes hidden, a filled outline could be edited with the appearance of magic occurring — the designer waving and clickin’ around a glyph responding to seemingly invisible “strings”. Cool as it was, it was also the most transparent and comforting method I ever used to draw and shape letters: seeing whatever visual crutches one needed, or none, with a single key while still being able to edit. Cheers!
