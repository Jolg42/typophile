The closest base fonts to my eye are Classic Roman MT [http://www.myfonts.com/fonts/mti/classic-roman/](http://web.archive.org/web/20140724103333/http:/www.myfonts.com/fonts/mti/classic-roman/ "http://www.myfonts.com/fonts/mti/classic-roman/") Pontif [http://www.myfonts.com/fonts/letterperfect/pontif/](http://web.archive.org/web/20140724103333/http:/www.myfonts.com/fonts/letterperfect/pontif/ "http://www.myfonts.com/fonts/letterperfect/pontif/") or a very similar Trajan. The faux Medieval touches Such as the X could come from a font like Mason Serif [http://www.myfonts.com/fonts/emigre/mason-ot/](http://web.archive.org/web/20140724103333/http:/www.myfonts.com/fonts/emigre/mason-ot/ "http://www.myfonts.com/fonts/emigre/mason-ot/") which has it as an alternate letter, or from Avqest [http://www.fontspace.com/gemfonts/avqest](http://web.archive.org/web/20140724103333/http:/www.fontspace.com/gemfonts/avqest "http://www.fontspace.com/gemfonts/avqest") or it might simply be a little creative design work. Unfortunately there is no standard way of accessing the open-type features (such as alternate glyphs) of an OTF (open-type) font. It depends on the application you are using and there are some Apps which still doesn't support open type features. You can read how to use them in Microsoft Word 2010 or later here: [http://www.magpiepaperworks.com/blog/wedding-tutorials/using-opentype-fo...](http://web.archive.org/web/20140724103333/http:/www.magpiepaperworks.com/blog/wedding-tutorials/using-opentype-fonts-in-microsoft-word/ "http://www.magpiepaperworks.com/blog/wedding-tutorials/using-opentype-fonts-in-microsoft-word/") and there is some information about open type features in Adobe Illustrator here: [http://mediamilitia.com/taking-type-to-the-next-level-with-alternate-cha...](http://web.archive.org/web/20140724103333/http:/mediamilitia.com/taking-type-to-the-next-level-with-alternate-characters/ "http://mediamilitia.com/taking-type-to-the-next-level-with-alternate-characters/")
