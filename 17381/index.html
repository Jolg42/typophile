Anonymous @ 19 January, 2006 - 4:41am
<cite>Monotype.com</cite> is what early versions of Andale Mono licensed to Microsoft used to be called. There is no difference between the two. The latest version of Monotype.com that I have is 1.20, last modified in April 1998. The latest version of Andale Mono that I have is 2.00, last modified in November 1998. Both are OpenType fonts containing 659 glyphs over five Unicode ranges and 21 code pages.
