Yes, this is the scribal pi. ’omega1’ is a misleading name that occurs in the Adobe Glyph List. Whether you call it /uni03D6/ or /pi.salt/ depends on whether you want Acrobat to map it back to the regular pi character or to U+03D6. Of course, you could include a redundant glyph in your font and use both names, which would be very Adobe-like.

_...does it matter if this alternate form maps back to pi? is this simply a stylistic alternate?_ Historically, yes, it is just a stylistic alternate, one of many. Some of the Greek stylistic alternates have been used in modern times as symbols in mathematics and the sciences, which is why some of them are separately encoded in Unicode. The scribal pi is one of these. I think in the majority of cases, unless specifically making a font for use in scientific documents, you would probably this glyph to map back to the regular pi, and not to U+03D6. Consider: a user creates a document in Greek and uses OpenType Layout features to access stylistic alternates including the scribal pi. Through some chain of circumstances, a PDF is created that contains only raw glyph IDs, no Unicode strings. Acrobat parses the glyph IDs to try to reconstruct the text for searching and copy/paste operations. If the scribal pi is mapped back to U+03D6, the text is no longer in Greek, and cannot be reliably searched. Of course, if you are creating a scientific document and are using the character U+03D6 in your text to signify something with a semantic difference to pi, then you have the opposite problem if the scribal pi gets mapped back to the regular pi by Acrobat. This is why Adobe’s glyph redundancy model isn’t really crazy after all.
