It looks like **[Avenir Heavy](http://web.archive.org/web/20141014074304/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=Linotype&ffam=Avenir%20-%20Heavy&fid=a18aff1363391533e205c2ae65649bba&fsize=60&text=012345&fit=1)** with modified /3 & /5 digits. For /3 & /5 you can also try **[Gautami (Bold)](http://web.archive.org/web/20141014074304/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=MS-Windows-Fonts&ffam=Gautami%20-%20Bold&fid=1cb82c6f93c51aa8dd7c7ea82cd641eb&fsize=60&text=012345&fit=1)** a font distributed with Microsoft Windows 7/8 to support the Indic script-Telugu More on Gautami: [http://www.microsoft.com/typography/fonts/family.aspx?FID=238](http://web.archive.org/web/20141014074304/http:/www.microsoft.com/typography/fonts/family.aspx?FID=238 "http://www.microsoft.com/typography/fonts/family.aspx?FID=238") ------------------ I found them using "Find my Font": [http://www.findmyfont.com](http://web.archive.org/web/20141014074304/http:/www.findmyfont.com/ "http://www.findmyfont.com")
