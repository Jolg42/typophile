The free font Sansman Bold is very close, save for the stroke ends (see the capital F): [http://www.whatfontis.com/Enter-Sansman-Bold.font?text=LevFlx](http://web.archive.org/web/20150317192728/http:/www.whatfontis.com/Enter-Sansman-Bold.font?text=LevFlx "http://www.whatfontis.com/Enter-Sansman-Bold.font?text=LevFlx") So that means if you want a dead-on match, it has to be Serpentine: [http://www.myfonts.com/fonts/linotype/serpentine/](http://web.archive.org/web/20150317192728/http:/www.myfonts.com/fonts/linotype/serpentine/ "http://www.myfonts.com/fonts/linotype/serpentine/")
