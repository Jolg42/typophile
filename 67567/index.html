**Computing Dictionary** tilde character "~" ASCII character 126. Common names are: ITU-T: tilde; squiggle; twiddle; not. **Rare** : approx; wiggle; swung dash; enyay; INTERCAL: sqiggle (sic). Used as C's prefix bitwise negation operator; and in Unix csh, GNU Emacs, and elsewhere, to stand for the current user's home directory, or, when prefixed to a login name, for the given user's home directory. The "swung dash" or "approximation" sign is not quite the same as tilde in typeset material but the ASCII tilde serves for both (compare angle brackets).

The regular tilde is a diacritic which is combined with other glyphs (like n to form ñ). It is sized and positioned to sit above alphabet characters. The ascii tilde sits centered on a line in a position aligning with math symbols like the equals sign. It is sized to match well with figures. It is used as others have said, in coding and as a symbol, (perhaps in linguistics?).

Dez: Yup -- in Symbolic Linguistics, it's the "Not" or "Inverse" operand, and [apparently](http://web.archive.org/web/20101003091659/http:/en.wikibooks.org/wiki/Geometry/Chapter_3) also in mathematics. In the C programming language it represents a bitwise "not"; while the logical "not" operand "!" toggles a value between zero and non-zero, the bitwise operand toggles each of the individual bits to their opposite. (You probably have to be a programmer to appreciate the difference.)
