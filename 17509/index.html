When Font Book “scans” a font, it is simply checking it over making sure its not corrupt and gathering information about the font so it’s ready to install. The only thing it can do to a font is install it. You can’t use it to reassign characters or anything like that.

Two things: Mac font suitcases use a file structure that is not recognized by Windows systems. Thus, if you copy a Mac font suitcase to a PC and back, part of the file may be lost in the transition, leaving you with a damaged (corrupt) font. In the Mac OS before OS X, the font suitcases of active fonts were open for read/write all the time the system was running. If there was a crash, open documents could be corrupted. This was the most common cause of corrupt fonts. There may be other ways that fonts (or any other files) may become corrupted, but I have not seen this problem come up very often on OS X.
