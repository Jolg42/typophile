You can invent your own vendor code, but you have to leave it lowercase unless it's registered. It's either Apple or Microsoft who does vendor code registrations. You can leave the UniqueID number blank, and should do so. Adobe, who invented UniqueIDs, no longer uses them in new fonts. There is a successor, the XUID, which we also mostly no longer use in new fonts. Regards, T\</font\>\</font\>

"pyrs" stands for Pyrus, the former company name of the FontLab distributor. Pyrus never made any commercial fonts, so fonts with the "pyrs" vendor code are probably fonts where the real vendor did not replace the default value with a custom one. The vendor codes can be registered with Microsoft: [http://www.microsoft.com/typography/links/VendorList.aspx](http://web.archive.org/web/20131010223231/http:/www.microsoft.com/typography/links/VendorList.aspx) Adam
