Perhaps that's because feature xxxx { sub by ; } xxxx; is not a valid syntax ... Try this instead -- custom ligature: feature liga { sub D a v i d by D\_a\_v\_i\_d; } liga; Be sure to create the 'D\_a\_v\_i\_d' glyph in your font. Compile, save as TTF or OTF, type your name into any sane program. Look, it's your name!
