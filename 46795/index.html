Object \> Path \> Outline Stroke then Pathfinder Palette \> Add to Shape, then Expand If your outlines are complex or dashed, instead of Object \> Path \> Outline Stroke, you will need to use Object \> Flatten Transparency with Vector/Raster balance at 100, and Convert Strokes to Outlines checked.

Anonymous @ 3 Jul 2008 — 2:42am
I came across this thread looking for a solution to the double stroke problem. Here's the solution that satisfied my needs, based on the techniques mentioned in this thread so far: 1. Convert Text to Outlines (cmd + shift + o) 2. Object \> Path \> Offset Path. Set offset to the stroke you would like. 3. Object \> Compound Path \> Release 4. Ungroup. (cmd + shift + g) 5. Pathfinder \> Add to Shape, then Expand. The result is a shape that mimics a text stroke.

Why do you need to put a stroke on it? Try doing a path-offset path (by the number of points you want) and it will create a separate shape behind the type that is slightly larger. That way, you aren't crowding the inner elements of the type: it stays completely intact, you are just building around it.
