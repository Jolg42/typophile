[It's been done.](http://web.archive.org/web/20131023141107/http:/office.microsoft.com/en-us/FX010857991033.aspx) ;-) Personally, I prefer a simple text editor when I'm writing. About the only extras I like to have are some simple formatting options (style, font, tabs), search and replace, and basic spell checking. Being able to paste in a graphic is handy sometimes. Everything else just gets in the way. The one I like best right now is TextEdit (comes with OS X), but I have used TexEdit (great shareware app) a lot, too.
