Hi Kristina, This from Nigel French's book _InDesign Type_: <cite>In InDesign create as many blank paragraphs as you have styles. Assign each of your styles to one of these blank paragraphs. Choose File &gt; Export and choose RTF as the file format. Open the text file in Word and choose File &gt; Print. In the Print dialog box, choose Styles from the Print What pop-up menu.</cite>
