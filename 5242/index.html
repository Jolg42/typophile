Baseline-mistake in InDesign: fonts are shifted

Hi guys,

The correct order in which the have to be stapled is: A (Blue), B (Green) and C (White).

Ren� -- It looks like Indy is determining the location of the baseline based on some characteristic in the font which varies in each of your versions -- for instance, the highest point of your ascender. Try setting the First Baseline Offset for each text frame to a consistent Fixed measure in the Text Frame Options dialog. -- K.

Kent is on the right track, but I think it will work better if you set the First Baseline Offset to "Leading". Also, make sure the leading is the same for all three text boxes. BTW, I wouldn't call this an error so much as an inconvenient default setting. Quark has a similar setting (I seem to recall) which used to default to the same thing. They must have changed it at some point, or perhaps your Quark default setting is different.
