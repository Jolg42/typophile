In the font window, click the codepages icon (on the right of the toolbar), then select Latin 3 from the drop down menu. ![](http://web.archive.org/web/20131017190846im_/http:/typophile.com/files/Latin3_5570.jpg) . The glyph cells will then show Latin 3 glyphs. If you select all of these and generate all you should have what you need.
