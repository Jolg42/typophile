It looks like **[Riesling](http://web.archive.org/web/20150317172026/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=Dafont-2&ffam=Riesling%20-%20Regular&fid=fd70966b8c5653bd491c8dcb21ad3149&fsize=60&text=The%20dog%20house&fit=1)** created for Bright Ideas magazine. Note that although this font is offered for download by dafont.com there are comments like the following which indicates this is not a free font and you should be extra careful if you want to acquire a legitimate license for a commercial project: > Bright Ideas Magazine > 50USD/month, edited by "Bright Ideas". Bright Ideas is produced under the direction of Creative Director Gail Conwell. > These fonts were not free. You can also use the following similar font: **[Mighty Ditey NF](http://web.archive.org/web/20150317172026/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=Nick-Curtis&ffam=Mighty%20Ditey%20NF%20-%20Regular&fid=30f739cdc8b571983a6bc7395eddf7e8&fsize=60&text=The%20dog%20house&fit=1)** by Nick Curtis [2007]

As Nick Curtis notes, Mighty Ditey NF is based on a typeface by Richard Nebiolo called Aphrodite for Photo-Lettering Inc. in the early 1970s. Presumably Reisling used the same source. For an interesting view on the license issue for Reisling see [http://www.fontsquirrel.com/fonts/Riesling?q=riesling](http://web.archive.org/web/20150317172026/http:/www.fontsquirrel.com/fonts/Riesling?q=riesling "http://www.fontsquirrel.com/fonts/Riesling?q=riesling") Don
