Any license that allows Cúfon embedding also allows proper "naked" referencing, I think, because it is hardly hidden. And those are only available from free (and/or open, public, whatever) sources. I've heard of "naked" embedding of the recent FontShop Axel release, which is corroborated by [the webfonts.info wiki](http://web.archive.org/web/20131014103813/http:/webfonts.info/wiki/index.php?title=Fonts_available_for_%40font-face_embedding) (which gets its info from [this post on the FontFeed](http://web.archive.org/web/20131014103813/http:/fontfeed.com/archives/last-hours-for-the-axel-promotion/)), so that looks good. Otherwise, the only list I know of _is_ that one on the webfonts wiki. Start there, or wait for the guys who've actually read all the recent EULA-updates from the big foundries, if any. — Rob Mientjes robmientjes.nl / rbmntjs.nl

\> _Any license that allows Cúfon embedding also allows proper “naked” referencing, I think, because it is hardly hidden._ Not necessarily. Cúfon is akin to sIFR, where a "raw" font is converted to another format and then linked from a webpage. So that's different from linking directly to a "naked"/"raw" font. Cúfon (and sIFR) cannot be used on the desktop, for example, so I can easily see licenses allowing those "embedding" solutions but at the same time disallowing direct linking to "raw" fonts.
