Actually, [FF Dax Condensed](http://web.archive.org/web/20131020041651/http:/www.fontshop.com/showfont.cfm?fid=FF.10001.0.0) is about the same width as [FF Dax Compact](http://web.archive.org/web/20131020041651/http:/www.fontshop.com/showfont.cfm?fid=FF.11416.0.0). The main difference is the latter has... "relatively small ascenders and descenders and the uppercase letters have the same height as the lowercase ascenders. This makes the typeface optically larger -- useful for headlines and posters where words must shout." - Hans Reichel
Anonymous @ 7 Nov 2005 — 9:07am
Typically the terms compact and compressed refer to a width narrower than condensed. This width is almost always used only for large display sizes. Condensed can be used (in small doses) for text. From what Stephen says, I infer that FF is using the compact description to indicate that it is a headline font. ChrisL
