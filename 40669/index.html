hinting and metrics problem

I posted the text below a month ago in the fontlab msn group but got no answer. I am posting it again here and hopefully I will get some answer.

“I have a problem with a monospaced font. I have manually hinted the font using the Bitmap Tool in the TrueType Tools. The problem is thatin some applications (like Flash - see the corresponding picture) the hinted version of the font (from 9px to 16px) is monospaced (which is correct) while in other applications (like Photoshop CS - see the corresponding picture - or even Notepad) the hinted version of the font is NOT monospaced! I can’t understand why this happens. All glyphs have a width of exactly 600px and the font works great while aliased.”

It looks like you may have hinted the advance widths of the characters accidentally at 14 ppm. Flash doesn’t show this because it’s not going to allow hinted advance widths (at least not the most current versions.)

Hello, I think the source of the problem are the bitmaps not the hints. The Bitmap Tool does not create any hints (or better instructions). Try to generate the font without the option “Export embedded bitmaps”. You find it in _Options - Generating OpenType & TrueType - OpenType/TrueType (.ttf)_ Regards Eigi
