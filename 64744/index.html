Wow, this totally bugged out. Awesome! Readability?... I'm not sure. Obviously, don't use it if legibility is imperative. For artsy projects, ya... maybe rework the illegibles, if you do want it readable. For "V", I would suggest an Avant Garde-ish tilt, with the left stem being vertical. You might try vertical stems with "W" as well. "I" should have a contained, non-open shape in center. Overall, I would say the maze theme is great, but if legibility is a priority, on a few letters you should compromise and have some enclosed shapes.
