AFAIK out BitFonter can open and save Palm fonts. In the same time it can open and save bitmap-only TrueType fonts. If autotracing is needed, then BitFonter can do it, but FontLab or TypeTool must be used to export outline TT font. BitFonter 2 will add a bitmap pixel-trace (Flash-style) feature. Best regards, Yuri
