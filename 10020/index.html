There is a lot of Gill used, so it may have been based on that. It looks more like a slanted [normal](http://web.archive.org/web/20080421031501/http:/www.myfonts.com/fonts/linotype/gill-sans/bold/testdrive.html?s=FIATC&p=60) than a true [italic](http://web.archive.org/web/20080421031501/http:/www.myfonts.com/fonts/linotype/gill-sans/bold/testdrive.html?s=FIATC&p=60) to me. The M seems to be based on [Futura Black](http://web.archive.org/web/20080421031501/http:/www.myfonts.com/fonts/efscangraphic/futura-black-sb/regular/testdrive.html?s=M&p=72) with an F drawn to suit. There looks to be a vectorised version of the logo in a PDF file [here](http://web.archive.org/web/20080421031501/http:/www.fiatc.es/internet/ges001.nsf/6bdb3b15e850b696c125697e003f8dc4/acd3f1a3ce759227c1256cec0042ab61/%24FILE/info_20.pdf)
