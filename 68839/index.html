Anonymous @ 27 Mar 2010 — 2:03am
Press yes. With regards to kerning the end swashes, I would set up class based kerning, eg @r [r r.end] assuming the left hand side of the glyphs are the same. If not, and you need to kern the swashes separately, you can copy and paste the resultant sring from the OpenType Preview window into the Metrics/Kerning window. I have suggested on the Fontlab forum that it would be good if the Metrics window could be set to apply OpenType substitutions, to make this process less of a hassle.
