Glyphs are just glyphs, you have to tell the font which substitutions to perform: In the OpenType panel, add a new feature (click the plus in the bottom left part of the panel) which creates a new empty feature (displayed in the top right part). There, enter something like: feature liga { &nbsp;&nbsp;&nbsp;sub f i by f\_i; &nbsp;&nbsp;&nbsp;sub f l by f\_l; &nbsp;&nbsp;&nbsp;[etc] } liga; which tells the OpenType interpreter to replace single "f" and "i" by the ligature glyph named "f\_i" (or "fi" if you call it like that). You can add other substitution commands by the same scheme. Karsten

Anonymous @ 3 Feb 2007 — 6:58am
Since glyph names still matter, you better name the glyph "w\_w\_w" so e.g. Acrobat knows it is a ligature and must be decomposed to w w w if you copy/paste text from a PDF. So: &nbsp;&nbsp;&nbsp;sub w w w by w\_w\_w; Or, if you like: &nbsp;&nbsp;&nbsp;sub w w w period by w\_w\_w\_period; Also, you can use contextual substitution: &nbsp;&nbsp;&nbsp;sub w' w' w' period by w\_w\_w; So w w w will be substituted only if period follows, but the period itself remains. (You could put w\_w\_w into your w kerning class. Might be that XPress7 ignores this then, I don't know, you have to try.) Karsten

But note that not all OpenType-savvy applications support contextual substitutions. The contextual ligature will work in InDesign, Illustrator, Photoshop, QuarkXPress 7 but will not work in Apple TextEdit, Keynote or Pages (under Mac OS X 10.4), while the plain ligature will work in all of the above.
