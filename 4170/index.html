It's Koch Antiqua Bold. Linotype has the [regular](http://web.archive.org/web/20080310230927/http:/www.myfonts.com/fonts/linotype/koch-antiqua/koch-antiqua/testdrive.html?s=Awards&p=48), but not the bold. There are other versions with the bold such as [Eva Antiqua Heavy SG](http://web.archive.org/web/20080310230927/http:/www.myfonts.com/fonts/spiecegraphics/eva-sg/eva-antiqua-hv-sg/testdrive.html?s=Awards&p=48) and [Kuenstler 165 BT Bold](http://web.archive.org/web/20080310230927/http:/www.myfonts.com/fonts/bitstream/kuenstler-165/kuenstler165-bt-bold/testdrive.html?s=Awards&p=48).
Anonymous @ 7.Apr.2004 11.01am
And if font quality is not a big issue (like for a personal project), David Rakowski digitized this for the Mac as [Lilith](http://web.archive.org/web/20080310230927/http:/www.erik.co.uk/font/serif.html) years ago. It's only saving grace is that it's free. The PC conversion is all over the Web ... like [here](http://web.archive.org/web/20080310230927/http:/www.moorstation.org/typoasis/designers/rakowski/dr4/davy_f4.htm).
