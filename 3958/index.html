Anonymous @ 5 Dec 2002 — 1:09pm
I haven't heard of any problems with Photoshop in particular, however using a given font in both Classic and OS X is not always intuitive--but it's easy enough to figure out. In short, it is possible to activate a font in OS X and have it NOT be active in Classic. You have to think of these as two separate operating systems (because they are). Make sure your customers are activating the font in both operating systems if they're using the font in both Classic and OS X apps. Hope this helps.
