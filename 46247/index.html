Jay: I’m sorry I have to disappoint you: there is no big master list. A number of special (or not-so-special) typeface genres come up here on typophile again and again. Some of them have been covered in [FontFeeds](http://web.archive.org/web/20150414223531/http:/www.fontshop.com/fontfeed/), like [The Extra Bold, Ultra Black Fonts](http://web.archive.org/web/20150414223531/http:/www.fontshop.com/fontfeed/archives/extra-bold-ultra-black-fonts/) (see also [The Fat Font Fad List](http://web.archive.org/web/20150414223531/http:/www.typophile.com/node/42643)). Others, like scripts, contructivist Bauhaus-style typefaces or lined fonts can be browsed on [Bowfin Printworks](http://web.archive.org/web/20150414223531/http:/bowfinprintworks.com/). The [TypoWiki](http://web.archive.org/web/20150414223531/http:/www.typophile.com/wiki/TypoWiki) has some lists, too. I remembered that we already had 2 or 3 threads about this rounded tech thing and searched for [Gravur](http://web.archive.org/web/20150414223531/http:/www.google.com/search?q=site:typophile.com%20gravur) and [T-Star](http://web.archive.org/web/20150414223531/http:/www.google.com/search?q=site:typophile.com%20t-star), using this [favelet](http://web.archive.org/web/20150414223531/http:/typophile.com/node/12436). Thus, I compiled a little list of the alternatives mentioned there, plus some more that came to my mind. No magic involved, only a little help from TextExpander (a Mac app that helps to insert links etc., similar to Typinator or RapidoWrite).
