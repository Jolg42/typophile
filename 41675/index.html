I guess you are using a mac computer? I would advise you to use fontexplorer. It's a free font management application. [http://www.linotype.com/fontexplorerX](http://web.archive.org/web/20131022043603/http:/www.linotype.com/fontexplorerX "http://www.linotype.com/fontexplorerX") Just download and copy to your applications directory. After that start up the program (just double click), then you can drag and drop the font files into the application window and that should do the trick for you. When you then start any application (illustrator, indesign) you will find the font in the font list of the application. good luck. dav2.
