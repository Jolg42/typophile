The _default_ resolution on Windows systems is 96dpi, but many people tweak it. Otherwise, 7.5 points should in theory render your font crisply. In the not-too-distant future, operating systems will automatically query the resolution off the display using Extended Display Identification Data (EDID), so a “pt” will, once again, be 1/72” or thereabouts.
