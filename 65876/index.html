There are some [minute differences](http://web.archive.org/web/20120104175752/http:/www.fontshop.com/fonts/downloads/mark_simonson_studio/proxima_nova_complete/?&sample_text=TOM%20FORD%20ENGLISHFRAN%C3%87AISITALIANO&sample_size=24): amongst others the the downwards point of the "M" is sharper, the cross-bar on the "A" is higher, the cedilla is different, but it's almost identical. If you need that atmosphere, that style, that look, get Proxima Nova. If you need an exact match, you'll have to look further.
