The Kindle can read MOBI, PRC, TXT, HTML, and DOC, in addition to protected AZW files from the Amazon store: [http://en.wikipedia.org/wiki/Amazon\_Kindle#File\_formats](http://web.archive.org/web/20081205034456/http:/en.wikipedia.org/wiki/Amazon_Kindle#File_formats "http://en.wikipedia.org/wiki/Amazon\_Kindle#File\_formats") With some tinkering, you can convert protected MOBI/PRC files into protected AZW files; they’re essentially the same format: [http://igorsk.blogspot.com/2007/12/mobipocket-books-on-kindle.html](http://web.archive.org/web/20081205034456/http:/igorsk.blogspot.com/2007/12/mobipocket-books-on-kindle.html "http://igorsk.blogspot.com/2007/12/mobipocket-books-on-kindle.html") My favorite hidden Kindle feature is turning off the justification with J when viewing the font size list. I guess none of that really answers your question, but if you’d like to send me files to test on the Kindle I’d be happy to.
