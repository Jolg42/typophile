Here is what I can think of right now. The free UK magazine Shortlist is pretty much only using Benton Sans from Font Bureau. British GQ is using Sebastian Lesters Soho, Berthold Akzidens Grotesk (and a serif). GQ (US) is using Titling Gothic from Font Bureau as well as a few others for features etc. Esquire US is using Mercury (Hoefler and Frere Jones) and Christian Schwartz’ Stag and Stag Sans. Sorry that links aren’t included. Busy at work. You can search for specific magazine titles here at Typophile and probably find a lot more info.
