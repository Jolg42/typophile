First, this is essentially [Melior](http://web.archive.org/web/20081202195903/http:/www.myfonts.com/fonts/linotype/melior/?refby=typographica). There aren’t a lot of alternatives to Melior (other than Zapf’s other [even more dated designs](http://web.archive.org/web/20081202195903/http:/www.fontshop.com/fonts/downloads/linotype/marconi_virtual/)), which is surprising considering the recent popularity of square sans serifs. Type makers, get on it! [RePublic](http://web.archive.org/web/20081202195903/http:/www.myfonts.com/fonts/suitcase/republic/?refby=typographica) is really the only thing I can recall that comes close.
