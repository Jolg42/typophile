Anonymous @ 13 Mar 2007 — 6:59pm
The best way, in most fonts, to get the x-height algorithmically. Get the bounding box of the lower-case "o"; take the height. Subtract the overshoot below the baseline. Cheers, T

Anonymous @ 15 Mar 2007 — 12:05am
There are various software libraries that allow you to access font files directly (rather than calling the Windows API for some information on installed fonts). I think using FreeType 2 would be easiest since it provides object-oriented access to both OpenType/TrueType and Type 1 fonts: [http://www.freetype.org/freetype2/index.html](http://web.archive.org/web/20131107235252/http:/www.freetype.org/freetype2/index.html "http://www.freetype.org/freetype2/index.html") For TrueType or OpenType fonts, you can read out the x-height included in the font using [http://freetype.sourceforge.net/freetype2/docs/reference/ft2-truetype\_ta...](http://web.archive.org/web/20131107235252/http:/freetype.sourceforge.net/freetype2/docs/reference/ft2-truetype_tables.html#TT_OS2 "http://freetype.sourceforge.net/freetype2/docs/reference/ft2-truetype\_tables.html#TT\_OS2") -- see sxHeight I recommend joining the FreeType discussion list to get more help. Regards, A.
