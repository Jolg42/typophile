I recently purchased Merlo. [http://typophile.com/node/44367](http://web.archive.org/web/20131020095746/http:/typophile.com/node/44367 "http://typophile.com/node/44367") The version from Vllg is actually better than the version Mario actually sells. It has more ligatures, dingbats, and several other important features like fractions. There also differences in the vertical bearings and kerning: vllg: ![](http://web.archive.org/web/20131020095746im_/http:/typophile.com/files/vllg_5649.png) felliciano: ![](http://web.archive.org/web/20131020095746im_/http:/typophile.com/files/felliciano_3949.png) However the version that he sells has alternates in the italics that I really love: ![](http://web.archive.org/web/20131020095746im_/http:/typophile.com/files/merloalts_5447.png) Also, Mario tells me there is an opentype version on the way soon. Hopefully all the features will be united. Until then, buy the Vllg version then request from Mario the version he has. I really love using it. Next on my list from him is Rongel. I really love his work. All my best, Mike Diaz :-)
