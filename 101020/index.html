Anonymous @ 2 Mar 2013 — 10:42am
Name-to-Unicode mappings are stored in .nam files in the \FontLab\Shared\Mapping folder, independent of the .enc files in the \Encoding folder. So you set up the name-to-Unicode mappings in a .nam file, and then use those names in a .enc file. In FontLab, you then need to use the 'Generate Unicode' dialogue in the Glyph/Glyph Names menu to select a default .nam to use. [Note that every once in a while, FontLab will revert to its Standard .nam and you will need to reset the default.] PS. I recommend creating your own .nam files, even if based on those provided by FontLab, rather than editing the Standard .nam.
