Anonymous @ 14 Sep 2005 — 8:57am
I spent a lot of time in magazines before I did this type design thing. Most magazine layout is based on the use of the odd numbered column grid. 5, 7, 9, or the 13 column grid that Willi Kunz made famous. This allows lots of different text column widths for features and departments, while also allowing white space to be managed in a organized way.
