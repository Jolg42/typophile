Anonymous @ 30.Dec.2003 6.13pm
The first thing to remember is that "supporting Unicode" is not a simple yes-or-no affair. With that in mind, every version of InDesign has used a Unicode based text engine. However, that is a separate question from compatibility with OS X text input methods. In previous versions of InDesign, it has often been the case that one could import text for certain languages, but not enter it directly in the application. I believe that InDesign CS has done a much better job of working with arbitrary Unicode-based keyboards, such as those which come with OS X or can be created by end users (using an XML-based syntax). However, I am not familiar with "PowerInput" so I can't say whether that in particular works. John's suggestion about the tryout version is a good one, except that AFAIK the tryout isn't available yet for InD CS. Regards, T
