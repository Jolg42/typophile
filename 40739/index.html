When a SWF is embedded in HTML, you can set its background color, like this (assuming you’re using the regular `<object>` tag): ` <param name="bgcolor" value="#000000" /> ` This will prevent it from showing a white square before the SWF finishes loading. — [omine.net](http://web.archive.org/web/20080111140824/http:/www.omine.net/)
