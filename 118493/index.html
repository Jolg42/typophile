If you care only about basic latin letters, I guess TeX Gyre adventor is URW Gothic L; cf [http://www.gust.org.pl/projects/e-foundry/tex-gyre](http://web.archive.org/web/20150317110013/http:/www.gust.org.pl/projects/e-foundry/tex-gyre "http://www.gust.org.pl/projects/e-foundry/tex-gyre") from the GUST (the Polish TeX Users Group) site: > **Adventor** > The package ( [download](http://web.archive.org/web/20150317110013/http:/www.gust.org.pl/projects/e-foundry/tex-gyre/adventor/index_html)) contains the most recent version of the TeX Gyre Adventor family of fonts in the PostScript Type 1 and OpenType formats. TeX Gyre Adventor is based on the URW Gothic L kindly released by URW++ Design and Development Inc. under GFL (independently of the GPL release accompanying Ghostscript). The Vietnamese glyphs were added by Han The Thanh. The Greek (basic) alphabet programmed for the TeX Gyre Adventor was inspired by the Kerkis package ( [http://iris.math.aegean.gr/kerkis/](http://web.archive.org/web/20150317110013/http:/iris.math.aegean.gr/kerkis/)). > > TeX Gyre Adventor can be used as a replacement for ITC Avant Garde Gothic (designed by Herb Lubalin and Tom Carnase, 1970).
