[Behind the Name](http://web.archive.org/web/20080906155243/http:/www.behindthename.com/php/view.php?name=caecilia) says it’s the German form of Cecelia. A search doesn’t turn up much of interest, but it appears in a lot of German pages with the spelling “Cäcelia” so I guess it would be like “zezelia” or something. Note: At some point German started using “ä” for the digraph “ae” (when it represents a single sound), so Latin words and names, like Caecelia, that were borrowed before that time also sometimes ended up with “ä” (though many names didn’t change).
