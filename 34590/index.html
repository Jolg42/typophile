Anonymous @ 26.Jun.2007 8.37am
Our main goal was to achieve the chaotic aspect of a realistic drawing tool and the emotion of a human handwriting!!! So we skipped the vector approach (loss of detail, greyscales, no color and inappropriate existing tools). We also wanted to have an unlimited number of versions for each letter or ligatures. And since Opentype features programming was also a lot of pain, we went our own way, much easier one ;-) Now, we can also add specific “behaviors” to fonts and letters (àla kerning pairs, special ligatures replacement, and new ideas too...), that do not exist on current font formats. We have developed our own tools not only to work on print projects, but we are also porting the interactive editors to the web. You can try our first demos, so our system can easily be implemented in any existing website (no plugin). For more interactions between type and the user, there will be a much more flexible and playful version too...
