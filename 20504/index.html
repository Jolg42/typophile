It seems that Adobe Inc. has removed the file FFOTEFontList.pdf, which documents the most recent font collection, from its Adobe website. But this file is still downloadable elsewhere on the Internet, e.g. here [http://www.xchangefr.com/pdf/FFOTEFontList.pdf](http://web.archive.org/web/20141012030945/http:/www.xchangefr.com/pdf/FFOTEFontList.pdf "http://www.xchangefr.com/pdf/FFOTEFontList.pdf") Furthermore, my two own websites [http://www.forgers.de](http://web.archive.org/web/20141012030945/http:/www.forgers.de/ "http://www.forgers.de") [http://www.sanskritweb.net/forgers/#adobe9](http://web.archive.org/web/20141012030945/http:/www.sanskritweb.net/forgers/#adobe9 "http://www.sanskritweb.net/forgers/#adobe9") document the entire Adobe font stuff - both old (PS) and new (OT).
