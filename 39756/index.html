Well, the font does not need any “locl feature tags”. It just needs languagesystems to be defined for all scripts present in the font. But Chris is right, the problem manifests itself when you assign a certain language for a certain text — for example, if you mark some font set in Cyrillic as “Russian”, it will then use the OpenType features registered under the “cyrl” tag.
