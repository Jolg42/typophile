The main thing that is distinctive is the \_R\_, which is found in a few fonts like Arboria Bold -- already suggested by Kevin -- GT Walsheim -- already suggested by Riccardo -- and Neutra Display [http://www.identifont.com/find?font=Neutra+Display&q=Go](http://web.archive.org/web/20150414205216/http:/www.identifont.com/find?font=Neutra+Display&q=Go "http://www.identifont.com/find?font=Neutra+Display&q=Go") The other letters are pretty common, including \_S\_ which is similar to Helvetica, Chalet, Newhouse, Nimbus, Pragmatica, Arial etc. perhaps the closest out of the box is GT Walsheim which hs both a similar \_R\_ and a somewhat similar \_S\_.
