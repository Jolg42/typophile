Raleway font - I'm not sure it's hinted for screen?

Hello

For a project I’m using Raleway through Google Fonts as a good alternative for Gotham. Or is it just about .woff-files that are not neccesarily hinted for screen usage?

This was done with ttf-files, which I downloaded straight from the Google Fonts website. Hi Laurens. If you modify a TrueType font, most often the hints are lost. It sounds like that might be what happened in your case. From what I’ve read, Google Fonts usually use autohinting. It should be no problem running your font through an autohinter again after the modifications. Ol’ geezers like myself prefer manual hinting, but it takes time and cost money if you have to pay someone for that time.
