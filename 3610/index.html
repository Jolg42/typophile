Stuart! I can't believe you would think this is anything but Helvetica. To be precise, it's not the version that we know and love/hate today, but the pre-digital display version from the metal/phototype days. If you've got an old Letraset catalog you can see it in detail. There was a thread last year where I illustrated the differences [here](http://web.archive.org/web/20071217223951/http:/www.typophile.com/forums/messages/30/7772.html). Scroll to about halfway down.
