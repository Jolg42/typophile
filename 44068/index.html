Anonymous @ 9 Apr 2008 — 1:16pm
Yes, via scripts. Check out [Peter Kahrel’s CharStyle](http://web.archive.org/web/20150227021557/http:/www.hilfdirselbst.ch/foren/Mapping_mit_CS3_%28Win%29_P339435.html#339435), [Dave Saunders’ PreserveLocalFormatting.jsx](http://web.archive.org/web/20150227021557/http:/indesignsecrets.com/plug-ins-and-scripts/) or something similar. <cite>Preserve Local Formatting: Dave Saunders wrote this cross-platform Javascript that can run through a selection of text (or the whole document, if nothing is selected) and replace locally-formatted bolds and italics (among others) with equivalent Character styles. The script adds the styles to the Character Styles palettes on its own,no need to create them yourself. Works in CS1 (change extension to .js), CS2, and CS3.</cite> — [InDesign Secrets.com](http://web.archive.org/web/20150227021557/http:/indesignsecrets.com/)
