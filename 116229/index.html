Looks like a generic monoline serif, like the upper case from a typewriter font, e.g. [http://www.myfonts.com/fonts/urw/prestige-elite/](http://web.archive.org/web/20140826130330/http:/www.myfonts.com/fonts/urw/prestige-elite/ "http://www.myfonts.com/fonts/urw/prestige-elite/") or a monoline serif like ITC Officina Serif [http://www.myfonts.com/fonts/itc/officina-serif/](http://web.archive.org/web/20140826130330/http:/www.myfonts.com/fonts/itc/officina-serif/ "http://www.myfonts.com/fonts/itc/officina-serif/") or Brix Slab Condensed [http://www.myfonts.com/fonts/hvdfonts/brix-slab-condensed/](http://web.archive.org/web/20140826130330/http:/www.myfonts.com/fonts/hvdfonts/brix-slab-condensed/ "http://www.myfonts.com/fonts/hvdfonts/brix-slab-condensed/") If you want to use it on an embroidery machine there are companies that sell fonts for use on the machines, e.g. [http://www.8clawsandapaw.com/typewriter-alphabet-embroidery-design.html](http://web.archive.org/web/20140826130330/http:/www.8clawsandapaw.com/typewriter-alphabet-embroidery-design.html "http://www.8clawsandapaw.com/typewriter-alphabet-embroidery-design.html") or [http://www.8clawsandapaw.com/back-to-basics-embroidery-fonts.html](http://web.archive.org/web/20140826130330/http:/www.8clawsandapaw.com/back-to-basics-embroidery-fonts.html "http://www.8clawsandapaw.com/back-to-basics-embroidery-fonts.html") Don
