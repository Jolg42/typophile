Best Serif Faces for the screen

I’m curious if people have any favorite “screen-friendly” serif faces. I am thinking headline/subhead size, image/flash based (I’m not talking about “HTML” text fonts here).

I ask because some clearly work better than others. for instance Bodoni with its extreme thins tends to break apart at anything other than large sizes. What are the serif faces that hold up better in digital media?

I’ve been poking around this site (please get the search feature working soon!) looking for a topic about this, but didn’t see one. If it exists, please point me to it.

Anonymous @ 12.Jul.2005 1.41pm
“Most fonts specifically made for screen use are only hinted with small text sizes in mind anyway.” I’m pretty sure this is not entirely true. The fact is that most fonts hinted for use on computer screens contain hints for all ranges of sizes. What is true is that some outline fonts designed to be hinted and used on computer screens have been designed with small sizes in mind, so like any good text face the lowercase is too big and spindly for larger sizes... What makes these fonts no better than anything else for you purpose, is that “headline/subhead size, image/flash based” specification. So, you are best off selecting something with niether small black, nor small white features, be they thin strokes, spaces ’twixt serifs, or anythinig else that a relatively unintelligent rasterizer would confuse with nothing, and make disappear, or something else that’d make these wee features look bigger than they are s’posed to be. So, yeah, don’t Bodoni.
