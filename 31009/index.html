There isn't an easy way to do this gradient in illustrator, but it's possible. You'll have to use the gradient mesh tool and create several small gradients that track around a circle.

Anonymous @ 30 Jan 2007 — 2:27pm
Create two rectangles (one black one white). Create a blend between the two. Set the blend to smooth color and to align to path. Create an art brush out of the blend. apply the brush to a circle. Increase the stroke weight until a point is created at the center. Let me know if any of this doesn't make sense. I was able to recreate your example perfectly. Josh
