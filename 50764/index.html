Hi Carolina, have a look at these articles: [Save backwards to previous InDesign versions](http://web.archive.org/web/20081026081654/http:/livedocs.adobe.com/en_US/InDesign/5.0/help.html?content=WSa285fff53dea4f8617383751001ea8cb3f-6d4d.html) [Can’t save InDesign documents to an earlier version](http://web.archive.org/web/20081026081654/http:/kb.adobe.com/selfservice/viewContent.do?externalId=329660) bemerx25 said <cite>No need to take it into CS2</cite> I’m afraid this is not correct. 1. Export from CS3 as INX 2. Open in CS2 (and make sure CS2 is updated to the newest version = 4.0.5) 3. Export from CS2 as INX 3. Open in CS (and make sure CS is updated to the newest version = [3.0.1](http://web.archive.org/web/20081026081654/http:/www.adobe.com/support/downloads/detail.jsp?ftpID=2448))

\> _If Adobe would provide some info re their XML-encoding, writing a utility that could process the various flavours of ID-files would be doable._ Starting in CS4, InDesign documents can be saved in InDesign Markup Language (IDML). InDesign Markup Language is an XML- based file format that allows developers to assemble and disassemble InDesign documents using standard XML tools and without having to open INDD files. _From [ID CS4 What’s new](http://web.archive.org/web/20081026081654/http:/help.adobe.com/en_US/InDesign/6.0/WSFE4C4DDD-967A-4cf0-845F-AB2B86FCC809a.html)_
