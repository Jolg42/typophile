The lowercase “s” in Avant Garde is so narrow that it looks like a mistake. If it were me, I’d pick a different typeface. There are a lot of other sans serifs out there that are clean and modern (Avant Garde looks really dated) and that don’t suffer from the “s” problem. Avenir might be a better choice. The yellow seems to be fine for that shape on the top right, but it seems to be a little too light for “natural”
