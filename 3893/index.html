Jay -- As far as I know, there is no "fix" except, as you found out, converting the file to another format like PDF, photoshop, etc. The problem with TT is that it's old technology. A fiery rip is newer technology based on postscript protocols, of which TT has none. Another quick fix might be to drop your TT font into Fontographer and recreate it as a PS font :-) but if you wanted it TT, I suppose, it would be so already. Good luck.
