Anonymous @ 6 Feb 2013 — 4:19am
Generating web font versions can be achieved in a number of ways. Font Squirrel offer a free online service which has a certain level of customisation but I would highly recommend testing the resulting formats before releasing them commercially. [FontLab have just released a beta version of Trans Type 4](http://web.archive.org/web/20150420093210/http:/typophile.com/node/99688) which has the ability to create web fonts, well WOFF and EOT anyway. FontForge is able to generate both WOFF and SVG fonts. Birdfont can generate both EOT and SVG fonts. There are also command line tools that can be set up to generate these formats and the page linked to below within the MyFonts site may help point you in the right direction: [http://www.webfonts.info/node/382](http://web.archive.org/web/20150420093210/http:/www.webfonts.info/node/382 "http://www.webfonts.info/node/382")
