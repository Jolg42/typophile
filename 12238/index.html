Type Cast: Font Preview Widget for Tiger

I just found this type widget on Apple’s widgets download area. I’ve used it a little bit, and it’s quite nice. It responds quickly and gives you a nice area to check out your type as you want to, check out the basic character set, and go to the font file itself, which is nice.
