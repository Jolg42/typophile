Mau - Font not found

I think it’s custom, but I think it might be easy to make if these are all the letters you need. The ‘a’ looks like a reversed G. The M looks like it could have been made by inverting the ‘u’ and extending the strokes, then overlaying it with the same new character. A flattened version of TC Europa could be a starting point to create this. Other squared fonts might work even better.

If you don’t see any other letters, then I think this is a custom job for sure.
