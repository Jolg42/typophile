I don't think it's possible, but that's a really great idea. Even better would be if you could create subsets of fonts to be displayed in the font menu, rather than every font installed. There's actually a system-wide facility for this on Mac OS X ("collections"), but it's only accessible in apps that use the system font picker (the Fonts window in Cocoa apps).

I use Font Explorer, not Font Book. But AHA! I just figured out how to deactivate the ones the system doesn't need! View: System Fonts: Show in Smart Sets. Then you can deactivate most of them (a few are clearly required, and are greyed out) then go to Hide Smart Sets et voila! Thanks Ralf.
