I can't think of any script fonts with such long connectors between the letters. You might be able to adapt Letraset's [Rapier](http://web.archive.org/web/20111214114748/http:/www.myfonts.com/fonts/letraset/rapier/) which is a late '80s design. Also look through all these scripts by: [Rob Leuschke](http://web.archive.org/web/20111214114748/http:/www.myfonts.com/person/leuschke/rob/), [Charles Borges de Oliveira](http://web.archive.org/web/20111214114748/http:/www.myfonts.com/person/borges-de-oliveira/charles/) [Sudtipos](http://web.archive.org/web/20111214114748/http:/www.myfonts.com/foundry/sudtipos/) Your example looks as if it was done in some kind of crayon or pastel. If you want this exact look it will be even harder to match with a digital font. You might be better off getting a few different script fonts and use them as a starting point to draw your own lettering.
