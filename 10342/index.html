Ute, Maury, to correct path directions in one or more glyphs automatically, choose Tools / Transform / Contour / Reverse all [N], then choose "Set counterclockwise (Type 1) direction" if you're making a font with PostScript outlines (Type 1, OT PS) or "Set clockwise (TrueType) direction". This operation will automatically correct path direction, not just reverse it. If the automatic correction has not produced the results you desire, you can manually reverse single contours by right-clicking (or Cmd-clicking) on a node and choosing using Reverse Contour. In FontLab Studio 5, the operation to correct contour direction automatically will be more readily available. Regards, Adam
