Anonymous @ 17 Dec 2014 — 8:56am
Neither of those sections are of much relevance to what you're asking. The 'unicode ranges' are used to set flags in the font which indicate which unicode blocks contain characters -- while some blocks are named for languages, it's unicode blocks that are being referred to here, and while unicode has been expanded to include many new blocks, new flags haven't been added for all of these. The encodings section again doesn't refer to languages, but to codepages which are largely obsolete since they are only really used by pre-unicode applications. If you're starting from an existing font there really isn't any way to tell FontLan that you want to delete all characters used by (e.g.) Hausa other than to delete the unwanted characters, and then let FontLab automatically recalculate the two font info panels you mention above. <cite>Thanks for your explanation, agisaak. The problem I have is that I don’t know which characters belong to which unicode set. I started off with Deja Vu, which has an extremely wide array of unicode sets.</cite> <cite>How do I know which characters/glyphs to remove, so I leave a unicode set complete? Looking up a reference and comparing them one by one, with roughly 2700 glyphs?</cite> I'm not really sure what you mean by unicode 'sets'. Unicode ranges are in many cases fairly arbitrary collections of characters and there's no real need to ensure that any of them remain complete. You mention you want to include Latin, Baltic (which is part of Latin) and Greek. Here's a brute force approach you might consider: Open DejaVu in unicode ranges mode, then mark all of the glyphs in the following ranges: Basic Latin, Latin 1 supplement, Latin-Extended A. In addition to the above, mark the following characters: 018F, 019F, 01FA-01FF, 0218-021B, 0237, 0259, 0275 and possibly 01C4-01CC and 01F1-01F3. Next, switch to codepages mode and mark all of the characters in MacOS Roman and Windows Greek. (many of these will already be marked). Next, look through the font and mark any additional characters that you want, such as mathematical characters etc. Finally, select all unmarked characters and delete them. You should have a reasonable character set for Latin and monotonic Greek.
