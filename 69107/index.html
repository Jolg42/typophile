@ Toby For the future: 1. Create a folder 2. Do one working step 4. Save vfb in the created folder 5. Close vfb 6. Copy the folder and give it a meaningful name 7. Open the vfb contained in the copied folder 8. Do the next step Then you have not only a protocol in the end, but backup files in the most cases. And even if you have 1000 folders in the end, disc space is not expensive. Unfortunately I actually cannot help. But maybe the FontLab people can help, if you send your vfb to them.
