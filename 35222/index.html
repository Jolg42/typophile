Anonymous @ 18 Jul 2007 — 7:09am
With just 9 icons, I guess you can import them individually. Save each one in a .svg file. Then in Fontforge, you select the slot where you want to put the icon, open it (say double click) and then in File \> Import you select "SVG" instead of "Image" and then click the file you want to import. [edit] On the [fontforge site](http://web.archive.org/web/20131016092627/http:/fontforge.sourceforge.net/) there is a pdf tutorial (second bullet).
