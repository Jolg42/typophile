Book covers of this era generally used hand lettered titles rather than direct application of fonts. There is a font with the almost identical letter-forms, but a narrower aspect created by Sol Hess in 1938 as Spire. There are digital versions by Ann Pomeroy that could be expanded in width. Use the regular version and substitute some letters, such as \_R\_ from the expert version. Really like these ones. First looks reminds me of [Georg Trump's Amati](http://web.archive.org/web/20141008164140/http:/luc.devroye.org/fonts-26218.html), some sort of cross-over between [Fenice](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/itc/fenice) (hemi-arrowheads serifs) and [Corvinus](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/search/corvinus) (geometric and squarish). Some alternatives: **[Amati RMU](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/rmu/amati-pro)/ [Amati AR](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/artypes/amati-ar)** (Fenice = Corvinus, main difference on /R leg), [Vincenzo](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/castletype/vincenzo) (Fenice \>\> Corvinus), [Flenja](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/stereotypes/flenja) (Fenice \> Corvinus), [Elongated Roman](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/aboutype/elongated-roman) (almost perfect but really too thin), [Latin Small MK](http://web.archive.org/web/20141008164140/http:/www.ffonts.net/LatinSmall.font) (Latin \>\> Fenice \>\> Corvinus), [Latino Elongated](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/itc/latino-elongated) (Latin \>\> Fenice \>\> Corvinus) ![](http://web.archive.org/web/20141008164140im_/http:/typophile.com/files/Amati-CEWeber-1952-GeorgTrump_5265.jpg) Second looks very modern. Alternatives: [Seagrass](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/bomparte/seagrass-bf) BF, Sudtipos [Storefront](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/sudtipos/storefront-pro) and [Buffet](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/sudtipos/buffet-script), [Stainy](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/mawns/stainy), CBdO [Sarah](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/charlesborges/sarah-script) and [Alpine](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/charlesborges/alpine-script), [Hemmet](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/mawns/hemmet), **[Dream Lover](http://web.archive.org/web/20141008164140/http:/www.myfonts.com/fonts/typeart/dream-lover)** (very close)
