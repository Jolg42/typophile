Anonymous @ 27 Sep 2008 — 6:53am
Quark has "kerning tables" which allow you to adjust the kerning in poorly kerned fonts. You do it once and the pairs stay kerned both throughout the document and whenever you use the font (in Quark). InDesign has no such feature, so that you have to manually kern the same pairs every time you use them. Obviously this is not a problem in fonts that are well kerned, but unfortunately they are not all so. I had hoped Adobe would put this feature into this upgrade. As Thomas explained it, the reason the feature hasn't been incorporated yet is that they want to make sure it works across all the CS applications. I argue that Illustrator and P-shop are not typesetting/layout programs to begin with, and that this feature would matter most to users of InDesign. To me, while overall I prefer InDesign, this is really a glaring oversight. See this thread: [http://typophile.com/node/7608](http://web.archive.org/web/20131108074044/http:/typophile.com/node/7608 "http://typophile.com/node/7608")
