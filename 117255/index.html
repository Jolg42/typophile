Based on the E and A, I would say this is a Caslon typeface. It is unlikely, I think to find this exact type in digital form, because each size in metal type was often a slightly different design. There are at least 6 different type sizes on this title page. The most similar font I have found is [LTC Caslon](http://web.archive.org/web/20140701093144/http:/www.myfonts.com/fonts/lanston/ltc-caslon/?refby=bowfin). Unlike many Caslons it has the single-serif C (as does Adobe Caslon Pro). - Mike Yanega
