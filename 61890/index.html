Renaming Glyphs in FLS5

Does anyone know if there is a relatively easy way (a python script which someone has made available perhaps?) to rename glyphs in FLS5?

Ideally, I’d like to find a way where I can rename glyph X and (i) have the glyph name changed in the code and classes, and (ii) have all glyphs named X.* changed as well. (i) is easy enough, but I don’t know of any simple way to achieve (ii) that doesn’t involve manually renaming all of the glyphs involved.

Any suggestions?

Try [GlyphRenamer](http://web.archive.org/web/20100203120232/http:/www.adhesiontext.com/typophile/GlyphRenamer.zip). All it requires is a text file with two columns of names separated by white space (can be one or more space characters or tabs). So something like, `oldName1 newName1 oldName2 newName2 oldName3 newName3` The script will only rename glyphs. It won't change the glyph names used in Classes or OT features.
