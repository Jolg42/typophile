Thanks George for the insight. These numbers combine an "over rounded" geometric letter style -- somewhat similar to Helvetica -- with an open top 4; characteristics that are found in some 19th century fonts, but very rarely in modern digital fonts. The closest I found were the numbers in a font designed by Steffen Sauerteig as a machine readable font using 1990s technology: [Typestar](http://web.archive.org/web/20130818070758/http:/www.myfonts.com/fonts/fontfont/ff-typestar/).
