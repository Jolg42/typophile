I don't have a list of common pairs, but I do have an extensive list of Russian words that I use to test spacing and kerning of Cyrillic fonts. These are derived from online Russian dictionaries and word lists. The idea is to show at least one example of every combination of two letters that occur in the language. Here they are: <!--attachment: Cyrillic_Kerning_source_files-37328.zip*mime_zip.gif*application/x-zip-compressed*17.7*Russian+kerning*Cyrillic+Kerning+source+files%2ezip --><!--attachment: Cyrillic_Kerning_source_files-37328.zip*mime_zip.gif*application/x-zip-compressed*17.7*Russian+kerning*Cyrillic+Kerning+source+files%2ezip --> <center> <br> <table border="1"> <tr> <td> <img src="http://web.archive.org/web/20131018224954im_/http:/www.typophile.com/forums/icons/mime_zip.gif" align="left" alt="application/x-zip-compressed">Russian kerning<br><a href="http://web.archive.org/web/20131018224954/http:/www.typophile.com/forums/messages/4100/Cyrillic_Kerning_source_files-37328.zip" target="_blank"><b>Cyrillic Kerning source files.zip</b></a> (17.7 k)</td> </tr> </table> <p></p> </center><!--/attachment--><!--/attachment--> Note that all these words are Russian, so I can't guarantee that a font kerned using these will work ideally for other Cyrillic-script languages. There may be, for example, combinations of letters that occur in Ukrainian that do not occur in Russian. If you are interested, I also have versions of these lists designed for use in the FontLab metrics/kerning window, i.e. using the /GLYPHNAME convention instead of the Cyrillic characters. However, the glyph names I use are Tiro's internal production names, not the AFII or uniXXXX names recommended by Adobe for the shipping font. We have a rather elaborate glyph name management system that allows us to switch back and forth between production names and final font names. If you're interested, I can fit you out with these files too.
