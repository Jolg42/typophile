Select WINDOW, NEW METRICS WINDOW, and click the KERN (green K) button. Then find the button that has an ellipsis (...) on it. Click that, then click OPEN, and you can load your kerning pair text file, and it will become you default kerning file. If you want to use the Auto-Kern feature, select the option of "All the pairs from the following list" (or words to that effect), and Auto-Kern will use you default file as well.
