I haven't tried it myself, but reportedly, OS X does not support Type 3 fonts at all, at the system level. (At least, some of Adobe's documentation says so.) Previous versions of Mac OS supported Type 3 fonts to some degree. They were not WYSIWYG because ATM couldn't render them for the screen - so the OS relied on scaled bitmaps from the font suitcase for screen display.
