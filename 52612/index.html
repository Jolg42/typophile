This question about how to use Roman numerals with a script typeface was recently posted on Ask MetaFilter, and I’m curious to see what answers would be given by people at Typophile.

I’m particularly interested in joeclark’s statement “You shouldn’t be using a script typeface for any application that requires all-caps text.”
