I don’t think this is a font. If it is, it’s very intelligent about contextual alternates and/or ligs. Those kinds of connections don’t come easy. What you need is a lettering artist or a lot of time from a type designer. If she can give up some of the custom connections she might like [Matinee Idol](http://web.archive.org/web/20090503110358/http:/www.fontshop.com/fonts/singles/comicraft/matinee_idol_regular/) or [MeMimas](http://web.archive.org/web/20090503110358/http:/www.fontshop.com/fonts/downloads/type_o_tones/memimas_family/).
