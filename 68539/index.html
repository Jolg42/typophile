Most broadcasting companies will use custom built software and hardware specific to their broadcast technology - that is to produce those live feeds with information, and overlaying credits. This is generally done in real-time - the mainstream applications are more for post production, special effects etc - which render out a self contained movie. News stories, scoreboard graphics etc deal with real time feeds so need a punchier system, and i wouldn't expect to see one of these outside of the studio it's used for. It uses the same sort of interface metaphors as mainstream applications though. Timelines, layers, importing footage, alpha etc etc. So any editing/composition software (Purple, Avid, Premiere) will give you adequate experience.
