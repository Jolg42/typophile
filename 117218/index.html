Very close to Courier (e.g. from Linotype) but it better matches to **[HY GungSo (Bold)](http://web.archive.org/web/20150317131805/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=Adobe&ffam=HY%20GungSo%20Std%20-%20B%20Bold&fid=9e1e0ba3e1e98ad6bf035e23df164636&fsize=36&text=New%20R%20s%20Packaging%2C%20Inc%20BMC%20layout%20IMPRESSION&wrap=2)** available from Adobe. I think the same glyphs are used in the Roman set of **Gungsuh** a Microsoft font supporting many codes pages and designed by HanYang I&C Co.,LTD.
