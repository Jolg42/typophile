Bitmap Font Advice: Formats

Hello,

I would like to create a script “font”, based on a really nice handwriting.

The pencil created a unique texture which I would like to keep. This, to my understanding, prevents me from using outline font formats.
Monochrome bitmap fonts (e.g. bdf don’t recreate that texture all to well, so I would like to know, how could I create a grayscale bitmap font, compatible with most applications.

Please excuse my ignorance. Fontlab doesn’t seem to support grayscale fonts (only monochrome bitmaps), is that correct?

When you add a bitmap strike to a fontforge file, you can specify the desired bit depth. For example, adding 19@8 to the list of strikes will produce a 19 pixels bitmap with 256 shades of gray. BTW fontforge allows to generate various bitmap formats, not just BDF. I actually think TTF with embedded bitmaps may be better for your purposes.
