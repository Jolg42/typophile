Roman numbers are simply combinations of certain Latin letters used as numerals. That is, there is no Roman numeral II, there is only a Roman number II written with the numeral I. Similarly, there is only a number IV, written with the numerals I and V. The same two numerals are used to write the number VI, in the same way as the Arabo-European numerals 1 and 6 can be used to write the numbers 16 and 61. It is a good idea, when talking about numerals and numbers, to be clear about the distinction. I think what you are looking for is a font that permits a stylised representation of a subset of Roman _numbers_, perhaps with a line above and below?
