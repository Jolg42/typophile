- Go to the "true type specific metrics" info box. - Change from "Automatic" to "Custom" and manually enter 845 and -260 on all the 3 ascender/descender boxes. And set the LineGab to zero. - Export again. Once in Illustrator/Photoshop, set the Line Spacing to the same size as the font. (For example, 700 and 700, instead of 700 and 840)
