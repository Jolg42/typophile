Read Karsten Lucke’s guide to font naming: [http://www.kltf.de/downloads/FontNaming-kltf.pdf](http://web.archive.org/web/20131020025728/http:/www.kltf.de/downloads/FontNaming-kltf.pdf "http://www.kltf.de/downloads/FontNaming-kltf.pdf") You might also want to search the build forum for other threads pertaining to naming issues. There are lots. As for your OT features, compare your OT code with some working fonts to be sure it’s correct, and make sure to compile the OT features before you create the fonts.
