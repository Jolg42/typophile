\_Triumph\_, also bespoke, is difficult to replace with a substitute. It seems to be based on the traditional 18th and 19th centuries English script but with a reduced inclination. For example Bo Berndal's Carl Beck ![](http://web.archive.org/web/20141203200347im_/http:/typophile.com/files/CarlBeckInUse_5416.jpg) [http://www.fonts.com/font/monotype/carl-beck/regular?SiteId=15](http://web.archive.org/web/20141203200347/http:/www.fonts.com/font/monotype/carl-beck/regular?SiteId=15 "http://www.fonts.com/font/monotype/carl-beck/regular?SiteId=15") Another script that attempted this is Aldo Novarese's Juliet, which has been digitized by Rebecca Alaccari and Patrick Griffin as Ambassador Script ![](http://web.archive.org/web/20141203200347im_/http:/typophile.com/files/AmbassadorScriptInUse_3698.gif) [http://www.myfonts.com/fonts/canadatype/ambassador-script/](http://web.archive.org/web/20141203200347/http:/www.myfonts.com/fonts/canadatype/ambassador-script/ "http://www.myfonts.com/fonts/canadatype/ambassador-script/") Don

Anonymous @ 1 Oct 2014 — 7:35am
Feather Script is an unusual combination of an classic structured lowercase similar to Englische Schreibschrift with casual swooping capitals. Feather Script seems to give some hint as to how letters other than the \_T\_ in \_Triumph\_ could work with the \_Triumph\_ lowercase. As for the second script -- Triumph Tailoress Script -- it's a far from casual design. I made a somewhat similar \_f\_ from scratch. ![](http://web.archive.org/web/20141203200347im_/http:/typophile.com/files/Recreated_t__6046.jpg) The exercise was surprisingly time consuming. Wish I could find a similar design as elegant and structured in an an existing font that is available to the public. Don
