This is the same request you posted in [http://typophile.com/node/117300](http://web.archive.org/web/20140725043136/http:/typophile.com/node/117300 "http://typophile.com/node/117300") but with a larger picture and a second font suggestion. In my opinion this is hand lettering rather than fonts as such. I have not been able to get any closer than Font Mesa's Brewmaster [Your "Brewmeister"?] [http://www.myfonts.com/fonts/fontmesa/brewmaster/](http://web.archive.org/web/20140725043136/http:/www.myfonts.com/fonts/fontmesa/brewmaster/ "http://www.myfonts.com/fonts/fontmesa/brewmaster/") and note that it was based on an old Budweiser logo. This type of script was popular in the decades around 1900. We sometimes lump them together as "Baseball" scripts. See for example Fenway Park JF [http://www.myfonts.com/fonts/jawfonts/fenway-park-jf/](http://web.archive.org/web/20140725043136/http:/www.myfonts.com/fonts/jawfonts/fenway-park-jf/ "http://www.myfonts.com/fonts/jawfonts/fenway-park-jf/") Philly Sport Script is close [http://www.myfonts.com/fonts/urw/philly-sport-script/](http://web.archive.org/web/20140725043136/http:/www.myfonts.com/fonts/urw/philly-sport-script/ "http://www.myfonts.com/fonts/urw/philly-sport-script/") except for the J. Another possible alternative is Arizona [http://www.myfonts.com/fonts/typesetit/arizonia/](http://web.archive.org/web/20140725043136/http:/www.myfonts.com/fonts/typesetit/arizonia/ "http://www.myfonts.com/fonts/typesetit/arizonia/") For this type of business a script based on an old Miller beer logo, like Font Mesa's Draft Beer [http://www.myfonts.com/fonts/fontmesa/draft-beer-classic/](http://web.archive.org/web/20140725043136/http:/www.myfonts.com/fonts/fontmesa/draft-beer-classic/ "http://www.myfonts.com/fonts/fontmesa/draft-beer-classic/") might be adaptable. As for "Barbador" I am not certain as to which font this is. Don
