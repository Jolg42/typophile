The current version of TLF does not support Contextual Alternates. The OpenType functionality currently supported can be leveraged using the classes in the [flash.text.engine](http://web.archive.org/web/20150122201907/http:/livedocs.adobe.com/flex/3/langref/flash/text/engine/package-detail.html) package. If you haven't done so yet, try the [Text Layout Demo App](http://web.archive.org/web/20150122201907/http:/labs.adobe.com/technologies/textlayout/demos/). The TLF team has recently made available its [source code on their blog](http://web.archive.org/web/20150122201907/http:/blogs.adobe.com/tlf/2009/12/new-and-updated-tlf-samples.html). The [Text Layout Framework](http://web.archive.org/web/20150122201907/http:/forums.adobe.com/community/opensource/tlf) forum is available for specific questions.
