Port Angeles, WA, USA – October 30, 2005.

Fontlab Ltd. announces the release of Photofont Start for Mac and Windows.

Photofont Start is a free plugin that allows any graphic designer to use photofonts in Adobe Photoshop and compatible applications for Mac OS and Windows. Photofont™ is an exciting new technology that allows users to create and use full-color bitmap type with transparency.

“Photofont opens completely new dimensions in the field of typography that was until now dominated by black-and-white type. Imagine computer letters with true calligraphic expression, visible brush strokes and paper structure. This is now possible with Photofont. And the best of all, the plugin is free,” said Ted Harrison, President of Fontlab Ltd.

The ability to create photofonts has been available for some time for users of BitFonter, Fontlab Ltd.’s professional bitmap font editor. Now, with the new free Photofont Start plugin, these designs can be easily used in the most popular bitmap-editing applications: Adobe Photoshop, Corel Painter, Macromedia Fireworks and compatible applications that accept Photoshop plugins on both Mac OS and Windows. The Photofont file format specification is based on open standards like XML and PNG and is publicly available. For more information visit the Photofont Start page at http://www.fontlab.com/photofont/

Planet typography

From A to Z… all the letters are on Planet typography.

Planet typography is a portal dedicated to typefaces and typography which proposes a comprehensive directory of links, a webzine which introduces the most famous contemporary type designers (in the October issue, Jonathan Hoefler, designer of Hoefler text), a typographic manual, a bookshop and a section dedicated to the freeware creation.

The site was launched in 1999 and is edited by a typo addict (but who does not work in the graphic design industry). Its target is to educate type users (all of us who have a computer) to the art of type creation and to vulgarize its unknown art.

A new version has been launched in October.

URL: www.planet-typography.com
