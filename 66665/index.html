Svenni, the Preview panel and the Metrics Window use the FreeType renderer with its own autohinting. This is not customizable. If you activate the TrueType or the Type 1 hinting tool, you will be able to preview fonts using the system renderers (TrueType or Type 1), and you can even select some different renderers (this is different for Mac and Windows versions of FontLab Studio).

On the Mac version, you only get a choice of renderers when you are using the Type 1 hinting tool: ![](http://web.archive.org/web/20131017115658im_/http:/typophile.com/files/t1hintingtoolmac_3642.png) The pop-up showing the choices is hiding in the tiny icon in the top-right corner of the preview pane.
