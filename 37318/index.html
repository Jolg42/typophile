<cite>I’ve just recently upgraded to both windows vista and adobe cs3...</cite> Are you running Suitcase 9.x or Suitcase 11? Suitcase 9.x has not been updated for Vista compatibility, although I can’t recall exactly how it fails. When Suitcase 11 for Windows was released, there were a few isolated cases where users had registry permissions set that prevented certain font types from activating. It wasn’t a problem with default installs of Vista, and I don’t know what caused it. I think that attempting to install any variation of ATM can also cause problems, and could potentially result in the behavior you’re seeing.
