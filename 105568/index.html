The line ends (some rounded, some square) indicate that the underline font - if any - is modified, and if your intention is to recreate the logo I suppose the simplest way is to recreate this simple geometry using e.g. Adobe Illustrator. If you want to use an existing font as a starting point, I suggest **Eloquence** by Sadalmelik Fontorium (1996, 1998) or **[Entangled Plain](http://web.archive.org/web/20131018052619/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=Dafont-1&ffam=Entangled%20Plain%20%28BRK%29%20-%20Normal&fid=27ad8b4f69b3ce8ed7d9e59355ededab&fsize=60&text=exec&fit=1)** free font by Ænigma Fonts
