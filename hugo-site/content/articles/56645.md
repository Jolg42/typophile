I’m considering offering my next release under a license that allows @font-face embedding. For SIFR I expect the user to buy a per-server font license, but for @font-face I think a per web site license is more appropriate. As a designer would you be willing to license a font for every web site you embed it in? And would you object to an @font-face license being priced higher than traditional licenses that allow unrestricted use for static content?
