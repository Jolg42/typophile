If you remove or add a node to a path in one master, the same will happen in any other masters, since they are really the same path. I’m trying to get a handle of multiple master for the first time, and came across a huge annoyance that has me questioning my workflow. I have the black weight (wt1) complete and I want to design a light (wt0) so I could generate the weights between. When I define the new axis (wt0), I have to “design” the light glyphs by editing the copy of the black glyphs. This severely limits my usual process of drawing, copying and pasting segments, using the knife tool, etc. I can’t work that way, or else it ruins wt1.  
Is there a way around this?

I know the point is to maintain the exact number of points, etc. Is there any way I can tell FontLab “Hey, I promise the points will be compatible when I’m done, so relax!”
