Scroll down to "WebKit and iTunes LP Internal Structure"

<cite>The iTunes LP experience is accomplished with HTML 4.01, CSS and JS. The interface feels very Flash-like, but there is no trace of it. The CSS animations are elaborate and smooth. Font files are referenced with an @font-face declaration in the CSS but there seems to be little to no use. Most text, even long passages of lyrics, is represented visually with a PNG file. I wonder if they originally intended to use font replacement for all text, but changed their mind.</cite>

Font licensing fun aside I wonder what the image-centric nature of the text does for accessibility?
