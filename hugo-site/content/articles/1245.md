Although the demo splash screens of both Bezier- and IkarusMaster in the light edition may cause some confusion (we will change this in the coming update), the functionality of the editors is only limited concerning the numbers of glyphs (256 maximum). All the other functionality is the same as in the full version. With the light version of DataMaster PostScript Type 1 fonts for Mac OS and Windows can be generated.        Although FM has been developed for extensive font production, it is actually quite easy to handle, although the first impression might perhaps be different. For full control over the functionality the learning curve might be steeper though, but it is worth the effort to learn the structure of the supporting files, like for instance the Character Layout files or the files that control the generation of the composites.        A short 'quick start manual':    To be able to open a font in Bezier- or IkarusMaster, it must be converted with DataMaster first into a BE or IK file. To test the modules, it is also possible to open a font from the FM Demo font folder, which the installer places in the FM (Light) folder (on the Mac by default in the Applications [Mac OS 9] directory). To work on the glyphs you need BezierMaster for the BE format or IkarusMaster for the IK format. When you open a font file in for instance BezierMaster, the first thing you will see is an overview of all the glyphs on the left from where glyphs can be opened, deleted or added. This will be quite unfamiliar for those who are used to Fontographer or FontLab, especially because you need to understand the way the database numbers work. As an alternative you can use the Font Administration window, from where you can work more or less the same way as in most other editors. In the Font Administration tool characters can be opened, copied and pasted using code pages, character numbers or Unicode numbers. The available batch functionality in the Font Administration tool is quite helpful. Changes in the Font Administration window are automatically saved.        You will notice that the available functionality differs when a Character Edit window is opened. You can switch between the glyph list on the left and the character window to see that for instance the Metrics Editor and Metrics Table are available when the glyph list is selected and specific tools for the contour editing will come available in case the Character Edit window is selected. In the Metrics Editor you can type the standard characters and use the character numbers to select all the glyphs from the database. To generate kerning you need to select a .afm or .fea file first. If you don't have such a file already you can generate an empty text file using a text editor, which you can give for instance the same name as your database. To change the appearance of the editors and for instance the behavior of the cursor, you can alter the settings in the Config menu which is available when the Character Edit window has been selected.        Generating a font is quite simple: just select the database in DataMaster and select the output format. The naming of the font is taken from the name of the database. Info for the auto-hinting is taken partly from the Font Header, which can be altered in both editors.
