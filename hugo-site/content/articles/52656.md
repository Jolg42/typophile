Greetings all.  
I have a very strange problem installing Type 1 fonts in my new Vista 64 bit.  
I’ve long used Extensis Suitcase to install and uninstall all sorts of fonts, with no problems whatsoever. Recently, I migrated to Vista 64-bit, and Adobe CS4.

I seem to have no problem installing and uninstalling True Type fonts via Suitcase 11, but when I install Type 1 fonts, it says the font is installed (there is a little yellow bullet next to the font to indicate that all is well), but the Type 1 font doesn’t actually get installed into Windows. Naturally, it does not show up in Photoshop’s font menu either.

I also tried using several other font managers (AMP Font Viewer, Bitsteam Font Navigator), but with exactly the same results. I have no problem installing/uninstalling True Type fonts, but not Type 1.

I then tried to manually install a Type 1 font, using Windows itself. That installed fine, and the font now showed up in Photoshop’s menu. However, I now can’t uninstall it.  
Windows’ native font utility tells me the Type 1 font is uninstalled, but it still shows up in Photoshop’s font menu. I can’t get rid of it.

Could anyone possibly tell me what’s going on? Are there gremlins in my computer?
