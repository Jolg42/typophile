Strange things are happening with the fonts on my iMac running MacOS 10.3.9 (and were happening previously). I cannot use Hoefler Text Ornaments in certain applications, particularly Word 2004. Any characters I type show up as empty squares.

If I try to use the HTO in TextEdit, it switches to Times. Bizarrely, it works fine in earlier versions of Word. The font looks completely normal in both Apple’s Font Book and Lemke’s FontBook application.

Similarly, I recently downloaded a trial of Broadsheet (from [www.texashero.com](http://web.archive.org/web/20081007190208/http:/www.texashero.com/ "www.texashero.com")). In TextEdit, if I start out typing something in Broadsheet, it switches to Lucida Grande after about the 6th character entered. Or, if I type a bunch of text in another font, then try to switch it to Broadsheet, it all converts...except the e’s.

Any ideas what is going on? I have tried flushing the Office font caches, but it has has no effect. I was hoping that my recent upgrade to Panther would (somehow) fix things, but that hasn’t worked either.
