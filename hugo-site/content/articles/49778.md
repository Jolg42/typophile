Hi all, I'm partly redesigning a historical periodical. A friend suggested Tankard's [Kingfisher](http://web.archive.org/web/20131018040130/http:/www.typography.net/type/font/kingfisher) for body text. In my opinion a great – conservative but fresh – original design. But is has no true small caps, which I really need – and will be using a lot. To automate small caps by using a character style is not an option.

So any suggestions would be more than welcome.  
Thanks in advance, Brieck.
