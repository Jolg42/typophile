Hi all,

originally I wrote [this test text generator](http://web.archive.org/web/20090807111149/http:/justanotherfoundry.com/tools/generator) for my own use but I think it may be useful for every type designer. It is similar to Miguel’s [adhesiontext](http://web.archive.org/web/20090807111149/http:/adhesiontext.com/) but the texts are synthesised using a different system.  
I hope it works with all your browsers and OSes - if you have any problems or suggestions just let me know! Implementing further languages would be fairly easy if there is need for it (Danish/Norwegian is already on my list).

Tim
