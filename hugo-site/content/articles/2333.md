Just a quick note (as I'm posting from work on a short break and apologies if this has been covered adequately elsewhere). Bitmap fonts in OS X break or misbehave. Here is a clue from [http://www.pixelhaus.com/#Fonts](http://web.archive.org/web/20130224075031/http:/www.pixelhaus.com/#Fonts)   
   
_"These are "bitmap" fonts designed for onscreen use, such as website design and Flash work. Since OS X 10.3 (Panther) seems to break these fonts, **I've converted them from old-style Mac OS 9 bitmap fonts to a True Type font "shell" with an embedded bitmap. In other words, they are not \*true\* TrueType fonts, as there are no font outlines.** The system should see them as TrueType fonts and allow their use regardless of this, although OS X's FontBook app does not seem to want to preview them. I realize this is awkward, but they are older fonts created back in the days before OS X. I've yet to receive a report of these fonts causing system trouble, but as always: use at your own risk!"_   
   
Emphasis mine.
