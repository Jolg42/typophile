This is Digita 7.5, my first attempt at a bitmapped font, and Fontographer is obviously NOT the best tool to use for the endeavor, I discovered to my frustration.   
   
In any event, this size is designed at 11 points. It was designed with classical proportions in mind, more or less. The numerical suffix designates 7 pixels above the baseline, and an average width of 5 pixels per character. I'm not entirely sure that this naming system will be as useful as it first seemed, but we'll see.... ![:)](http://web.archive.org/web/20150414081102im_/http:/www.typophile.com/forums/clipart/happy.gif)   
   
I really hope this displays properly. ![:)](http://web.archive.org/web/20150414081102im_/http:/www.typophile.com/forums/clipart/happy.gif) Your comments are welcome, and very much wanted....
