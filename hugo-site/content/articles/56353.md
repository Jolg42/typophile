Should I create a cell for each direction (left, right, up, down) for each symbol? Or, is one sufficient and the user can point them wherever they want to? I’ve noticed in other symbol fonts that there were redundant pointers for each direction.

On the other hand, maybe dingbat fonts are redundant?

Opinions? Comments? Rude gestures?
