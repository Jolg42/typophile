But, it sounds like you want to build a typeface. Typefaces are systems of interchangeable parts that repeat and have to function in any combination, giving a consistent pattern. There’s room for expressiveness, but it has to be distributed and balanced across all the components (letters).  In my opinion, Eric Gill never really understood this functional difference; he was a lettercarver till the end.  Try setting a few words where the shape repeats: hidden, padding. Then some where the d is paired with similar shapes: armada, audacious. Is your u going to use that tail too? Set words that combine the d with anything else, v, s, t, b, m, n, o. You might want to spend some time drawing the “boring” letters like d, r, i, n, that make up a significant proportion of printed text. If your types have several strong letters and several weak ones, that doesn’t help the typeface, or the reader. You’ll want to have the same confidence in drawing s or j that you have drawing an a. Even a lettering artist needs that skill. Type designers these days are called upon to not only deliver these alphabets but ones from other scripts like Cyrillic and Hebrew.  Look at Jeremy Tankard’s Enigma. In it there are a lot of unconvential shapes, yet he makes them work. It’s not impossible, but it does require a lot of attention to consistency and harmony among the different parts. It’s type, not lettering. Same with Goudy’s Californian. It works. So I’ve been scanning some sketches and drawing over them in Fontlab/Illustrator…when i got to this one it boiled up a question: is the bottom serif of the letterform ‘d’ in this example considered an ‘ok’ practice?

i went browsing through my small collection of fonts and looked at a few examples online and all i seemed to find were bottom serifs that were nearly the same as the ascender serifs except flipped a little.

so is the hook serif considered ok? it might be a stupid question, but i’m pretty new to this and it’s my only pencil sketch that was really like this (mostly because i don’t draw d’s very well and obsessively draw a’s) also, if this is a method of serif others have used, what is the benefit of ending a letter in this manner in regards to text faces and in contrast to the sharper angled ending serif?

please note, these sketches are very rough and really unrefined. only for question purposes completely.
