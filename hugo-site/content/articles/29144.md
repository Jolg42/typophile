Is there a way to denote a paragraph break in the OpenType Feature Definition Language?

The paragraph break as such (not the pilcrow \_glyph\_, that is, but the \_character\_, so to speak), has no code point in the font, but is implemented through and handled by the text processor or text setting engine. So, unfortunately, I don't see a way to incorporate it in an OpenType feature.

It might be very useful to have this, though; one may want to have for example end swashes only at the end of a paragraph.
