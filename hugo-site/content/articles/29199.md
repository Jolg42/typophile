I posted a query to the InDesign [forum](http://web.archive.org/web/20131108074341/http:/www.adobeforums.com/cgi-bin/webx/.3bc20e3d) but to no concrete avail. Anyone know an easy way to add vertical (left/right) rules to a paragraph? Stuffing the copy into a table with a left/right stroke doesn't work if the text is more than a page long (InD can't "flow" a table cell across 2 frames), and I'd like to avoid simply adding rules manually as text-flow isn't finalized and thus things are going to move around a bit. Seems that it shouldn't be much more complicated than horizontal rules, but...
