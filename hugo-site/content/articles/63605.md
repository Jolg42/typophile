Hi there,

I am generating a 'non style-linked' font family and for that reason I am not using the checkboxs 'Font is Italic', etc.  
Following advice given in this forum, I set a value in the 'Italic Angle' field (Font Info \> Metric and Dimensions) because in that way styles are better listed in applications like InDesign.  
The problem is that when I test the generated OT font in Font Validator, it seems to find an inconsistency in Italic styles:

'The italicAngle is nonzero, but the head.macStyle italic bit is no set'.  
The error is marked red in the report.

Is it really something to fix or I should ignore it?

Thanks in advance.
