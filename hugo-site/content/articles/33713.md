[Indices](http://web.archive.org/web/20150121023752/http:/typophile.com/wiki/Indices) : [Terminology](http://web.archive.org/web/20150121023752/http:/typophile.com/wiki/Terminology) : Squooshed

A term used to describe type that has been horizontally or vertically stretched or condensed using graphic design software. Glyph scaling in this manner is almost always inadvisable and is often a sure sign of amateur typography. Space is best saved by reducing the type size or using a condensed (or extended) version of the font professionally drawn by a type designer.

“Squooshed™” is a trademark of [Miss Tiff Industries, Inc.](http://web.archive.org/web/20150121023752/http:/www.typophile.com/node/6471)

See also [Faux Formatting](http://web.archive.org/web/20150121023752/http:/typophile.com/wiki/Faux%20Formatting).
