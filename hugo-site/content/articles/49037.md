I found some interesting theatre posters ages ago and loved the lettering, especially the first one with its watery curves and painty texture. Would you start with a paintbrush and practise drawing the character shapes, swirls and get some interesting textures? If so, what kind of brush/paint/paper/canvas would you suggest? Or start with a scan and build the missing characters from existing elements?  
Should I try to keep the messiness or clean up the edges? Are there other fonts like these? Are there any copyright issues with trying this?
