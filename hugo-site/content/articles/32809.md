I'm making an OpenType handwriting font for a client, so all characters have long lead-out strokes to flow nicely into the next character. However, the client doesn't want these long strokes at the end of every word. So I'm wondering how I can replace the regular characters (eg. y) by end characters (eg. y\_end), so in the word 'every' only the y would change. I've looked through the needle-in-a-haystack manual with no luck. How does one specify just the last letter of each word to change to an alternate form?

Any help would be much appreciated.
