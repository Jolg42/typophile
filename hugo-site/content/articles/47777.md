Only include in this lookup any glyphs that you eventually want to be positioned with the attach3 anchor.  2. Export this lookup to a .vtl text file.  3. Open the .vtl file in a text editor. Search for  attach1\\\"  and replace with  attach3\\\"  i.e. rename the anchors without changing the attachment offsets. Save.  4. Import the edited .vtl back into VOLT. If asked if you want to replace existing attach3 anchors, say YES.  This will create attach3 anchors with the same positions as attach1 anchors, and these can now be edited for specific base glyphs. Note that anchors are stored internally in VOLT, so if you have existing lookups that reference both attach1 and attach3 the latter will inherit your new positioning.
