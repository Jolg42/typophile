If so, probably you got more space between text and footnotes on previous page simply because there is no text to add there (as the remaining lines were transferred to the next page).  These transfer-to-next-page are common when notes are extensive. ID needs to show references and notes in the same page. When you increased the space, it couldn't show both reference and note to the 4th one, so the transfer was mandatory. This causes different lenghts of main text areas, which can be avoided if you choose the vertically justified text box option.  Also check if you did let ID break footnote texts through pages.
