I like to open the program we use at work, Multi-Ad Creator, and type my specimens for print in that program (for two reasons: I like using it, and my fonts are for work, so they need to work with this program). However, with one font I have been creating, I have a problem with the program crashing while trying to create an EPS. At first I thought it was a problem with the program, but it appears to be a problem with a few of the number characters in my font. As long as I don't type any of the certain numbers that cause the problem, the EPS comes out fine and Distiller makes a PDF with no issues. I have examined and re-examined the numbers, I cannot find anything different in these shapes than every other glyph in the font. Does anyone have any ideas as to what might be causing these crashes?
