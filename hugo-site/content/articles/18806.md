On a Mac [Classic] each file can have two parts called forks. The _data fork_ holds data (text, images, etc.). The _resource fork_ holds resources (icons, fonts, menus, sounds, etc.). There are actually two files linked to one name in the file system. PCs only have one file linked to each name.   **Fork:** A fork is a stream of data associated with a file name in a file system. Macintosh HFS files have two forks. PC FAT and FAT32 files have one fork. NTFS files can have many forks.
