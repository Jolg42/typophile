I think it looks quite interesting, although its looks a bit more like a 'techno' font than a fraktur. A, O and T do have real fraktur characteristics, the rest is more hybrid. I think it is also hard because fraktur typefaces are hardly ever set in all caps (except perhaps for one or two words) and for good reason: it is almost illegible in all caps! So I guess if you want to make this work as caps only you will have to go for this kind of hybrid.
