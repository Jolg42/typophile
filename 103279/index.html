'Le Chat Cambrioleur' must be **[Alternate Gothic2](http://web.archive.org/web/20150107185459/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=Bitstream&ffam=AlternateGothic2%20BT%20-%20Regular&fid=ee80a9129db5d24062f0d322cdc55900&fsize=60&text=LE%20CHAT%20CAMBRIOLEUR&fit=1)** although **[Trade Gothic (Bold Condensed No. 20)](http://web.archive.org/web/20150107185459/http:/www.findmyfont.com/index.php/fonts/font-preview?fset=Linotype&ffam=Trade%20Gothic%20-%20Bold%20Condensed%20No.%2020&fid=66f2d1e45be09de0c1e35f906cf0a4d8&fsize=60&text=LE%20CHAT%20CAMBRIOLEUR&fit=1)** is also close ------------------ I found it using "Find my Font": [http://www.findmyfont.com](http://web.archive.org/web/20150107185459/http:/www.findmyfont.com/ "http://www.findmyfont.com")

'Auteur Eyewear Collection' must be **Bastard** by Michael Cina (Test Pilot Collective, 1998) but I don't know if there is any legitimate sources now to acquire Test Pilot Collective fonts. You can read more about them on Luc Devroy pages: [http://luc.devroye.org/fonts-26009.html](http://web.archive.org/web/20150107185459/http:/luc.devroye.org/fonts-26009.html "http://luc.devroye.org/fonts-26009.html")

[Test Pilot Collective](http://web.archive.org/web/20150107185459/http:/www.testpilotcollective.com/tpc/). Bastard was given away as a free font toward the end of 2001 (I have a copy of the User License). If you want to use it commercially, I'd contact them. If you simply like the squared, thick n' thin style of Bastard, it seems to have been heavily influenced by [Eden Bold](http://web.archive.org/web/20150107185459/http:/old.myfonts.com/fonts/redrooster/eden-pro/).
