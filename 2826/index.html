Anonymous @
_Cyrillic miniscules are already functionally small caps anyway._ No, they are not _functionally_ smallcaps: many of them are \<i\>visually\</i\> similar to small versions of the capital letters in upright style (not in cursive italics), but there is a typographic function for actual smallcaps in Cyrillic text just as there is in Latin text, e.g. acronyms, running heads, etc. The typical difference between Cyrillic smallcaps and Latin ones is that the former tend to be slightly taller, in order to distinguish them more clearly from the similar lowercase letters, whose proportions also differ. This is something to be kept in mind when designing fonts that combine support for multiple scripts. A few years ago I was commissioned to design a set of Cyrillic smallcaps for Minion Cyrillic for a publisher who needed them for a book that included some words that always appeared in all-caps.
