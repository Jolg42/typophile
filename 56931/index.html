I had to use a vector logo in Word once. It was a pain in the ass, and I ended up using a high res bitmap image instead. Google "vector MS Word" for more on the subject! Windows WMF and EMF are vector formats. Just copy your Illustrator logo to the clipboard, and then in Word, select Edit \> Paste Special \> Picture (Enhanced Metafile). If Enhanced Metafile isn't an option, choose Picture (Windows Metafile). If both are available, EMF is better. If you want to save the logo in .wmf or .emf format, there are any number of programs that will extract those formats from the clipboard.
