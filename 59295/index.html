Scripts with such character don’t really need a mark, IMO. I’m not really the one to give advice (I’m usually the amateur in need of it), but I’d still like to mention a few things here: First and foremost it doesn’t strike me as consistent. Maybe figuring out the skeleton and using a single tool to draw it out before you start finetuning the outlines will be helpful. Second, I’m having problems recognizing some characters, most notably ’g’ and ’k’.
