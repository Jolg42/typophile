Another solution, used by Dennis Ortiz-Lopez and others, is to create several fonts that can be layered, one on top of the other. The base font would be the letter shape itself (in solid B&W form). The next font would be, say, a bevel effect, also in solid B&W form, which would be printed in a greyscale or any color determined by the user of the font. Another font could be an outline layer, an inline layer, etc. Ortiz-Lopez' work can be seen at: [http://ortiz-lopez.com/index.html](http://web.archive.org/web/20131020201736/http:/ortiz-lopez.com/index.html) David

If you are going to experiment along the lines of halftone screens, it might be an idea to experiment with line patterns instead of dot patterns, it might help reduce file sizes / complexity and can look rather nice if done well. As for bitmap fonts, they do exist, certainly on the Mac, and can be edited with packages like FontLab's BitFonter ( [http://www.fontlab.com/html/bitfonter.html](http://web.archive.org/web/20131020201736/http:/www.fontlab.com/html/bitfonter.html)).
