You probably need to clear your font caches. You can do it with a Utility like [Font Finagler](http://web.archive.org/web/20130823100609/http:/homepage.mac.com/mdouma46/fontfinagler/). This is pretty much required if you want to develope and test fonts on OS X anyway. Changing the font name during testing each time you make a new version (the font name, not the file name) can help, too.
