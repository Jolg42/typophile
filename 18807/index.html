_I want to know how to determine if they’re faux or real._ In general, this is pretty easy to spot. Given that they were well designed, true SC are better proportioned and have the same weight (e.g. aproximately the same stem width) as lowercase characters. If you’re not sure, print out a passage of text with some embedded words typeset in SC and you’ll see the difference. If you don’t want to print and are using InDesign, just open the Glyph Palette and visually check for the presence of SC. _I’m pretty sure Post-Script are ‘printer’ fonts and TrueType are the ‘screen’ fonts. Is this correct?_ No. (Not this theme again. When will this and other related myths be wiped from the planet? :^/ :^) Please read: [TrueType versus PostScript](http://web.archive.org/web/20080628180851/http:/www.typophile.com/node/16695)
