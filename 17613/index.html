Yes. There are a million fields in the type info: Copyright notice, Info, etc. Different fields are used by different formats, and maybe someone can clear up which go with which. But, you can put your client’s name somewhere in the copyright notice field, as Font Bureau did (still does?). It would require either generating fresh fonts for every client, or decompiling and recompiling (using TTX for example) the fonts with the new info inside. Note that if you can add this info, your client or a pirate - if they know the tag is there, and are looking to cover their tracks - can remove the tag using TTX or importing, tweaking, and generating the font using a font creation software such as FontLab.
