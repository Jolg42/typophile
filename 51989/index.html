Anonymous @ 23 Nov 2008 — 3:19pm
The plane is almost certainly too detailed compared to the rest of the logo. So simplify it a bit. Ampersand adds quite a substantial amount of detail into the logo but it's too sans serif to complement the details of the plane. To me the most promising logo was #4 in the first batch of logos. It connects both letters and the plane and doesn't leave R outside of the mark. Logos with only half the plane don't work with me. One more thing. If you'll combine outlines with flats (as in logos in the second batch), be very careful about it because it usually tends to complicate application if not done properly. But other wise type choice is very good for R&D lab. \_\_\_\_\_\_\_\_\_\_\_ _Robert Koritnik_
