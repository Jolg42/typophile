First of all, this font is set to "Editable Embedding". So there is no restriction on embedding the fonts into a PDF. We hear problems like this from time to time (with Microsoft fonts, even though embedding is set to Embeddable). So my suspicion is that it is a problem with Adobe Acrobat and its settings that prevent certain fonts from being embedded. Has anyone else experienced this problem with other fonts set to Preview & Print or Embeddable Embedding? Ascender has a license to a wide variety of Microsoft fonts, but unfortunately this is one of the few that we cannot offer. We have tried to obtain the rights from the original designer/foundry without success. So there is not much further I can suggest to help.
