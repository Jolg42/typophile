For exceptions use single kern pairs at the top of the kerning file. #exceptions pos Q by comma -20; #you can use "enum" to work with classes for exceptions - enum spiltes the classes into singles during compilation enum pos @\_kern\_Q by @\_kern\_... -20; Be sure, no glyph is part of two or more classes! -- [astype.de](http://web.archive.org/web/20141115074551/http:/www.astype.de/)--

<cite>pos Q by comma -20;</cite> Andreas, you were dreaming of substitution -- no 'by' in pos commands.&nbsp;&nbsp;;-) <cite>which seem to be my exceptions</cite> Looks like there is something wrong with classes: one glyph appearing in more than one leftside class, or in more than one rightside class. I think you should check your class definitions first. About 3400 kerning pairs <cite>may be</cite> (but not necessarily are) critical. If you generate fonts with AFDKO 2, you can also try to kick out lines with "subtable break" and add an explicit lookup definition with 'useExtension', so your kern feature looks like this (please exchange parentheses by braces): feature kern ( &nbsp;&nbsp;&nbsp;&nbsp;lookup kern0 useExtension ( &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;pos A B 12; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;pos B C 32; &nbsp;&nbsp;&nbsp;&nbsp;) kern0; ) kern; But mind that FLS5 cannot compile this, and that such a kern feature will be interpreted only by a few OT-savvy applications like those of Creative Suite.

If you are having problems resolving class conflicts, here's what works for me. ![](http://web.archive.org/web/20141115074551im_/http:/typophile.com/files/Kern1_5402.png) First, select "class kerning" in the metrics panel. . ![](http://web.archive.org/web/20141115074551im_/http:/typophile.com/files/kern3_3773.png) This has several benefits, one of which is to highlight class conflicts in red. Here, v and c are the master characters in their classes, and y is included in the "v" class. Therefore, when I attempt to apply a different kern value between y and c, FontLab marks it with a red number warning. . ![](http://web.archive.org/web/20141115074551im_/http:/typophile.com/files/Picture3_3947.jpg) This value is also listed in red in the kern pair table at the right of the metrics window, enabling one to scroll throught the entire kern pairs in a font, looking for conflicts.
