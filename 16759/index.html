Anonymous @ 13 Dec 2005 — 6:37am
Among sans faces, [Simian](http://web.archive.org/web/20150123175210/http:/houseindustries.com/index.php?page=showfont&id=24&subpage=viewfonts) is in the same sort of space as Section, and very stylish. The display versions are a bit weird, but the text versions might work for you. More self-conscious but very well done is [Cholla](http://web.archive.org/web/20150123175210/http:/emigre.com/EF.php?fid=84), which I saw used here in Washington DC at the Hirschhorn Gallery. Also a bit along the self-conscious line, but which I like better is [Amplitude](http://web.archive.org/web/20150123175210/http:/fontbureau.com/fonts/Amplitude), which, like Simian is by Christian Schwartz. Jeremy Tankard's [Aspect](http://web.archive.org/web/20150123175210/http:/www.typography.net/type/aspect.htm) is both both architectural and avant-garde. If you like stuff that is somehow both modern and Baroque you will go nuts over [Storm's faces](http://web.archive.org/web/20150123175210/http:/www.stormtype.com/)
