  2. In his examples he writes things like 20 pt head on 4 pt lead. Would this be 20 pt font size and 24 pt leading in my inDesign type pallet? I know this is a stupid question but when I set up three text blocks side by side in inDesign it doesn’t look like his examples.

Suitcase for Windows now includes CS 3 Auto-activation Plug-ins

Extensis has released an update to Suitcase 11 for Windows (v11.0.1), which includes auto-activation plug-ins for InDesign CS 3 as well as Illustrator CS 3. The update page is here.

On the Mac side, Suitcase Fusion currently provides a plug-in for Illustrator CS 3, but not InDesign CS 3. So, for the first time I can recall, Windows font management users are a bit ahead of the Mac side. InDesign CS 3 plug-ins are in development for the Mac though.
