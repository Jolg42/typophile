Primes vs. Foot Marks...

Aren’t primes and foot marks two distinct typographic marks? I’ve always been under the impression that foot marks (and inch marks, for that matter) have vertical axes, while mathematical primes (and double-primes) ought to be slanted. Please clarify this, someone! :-)

They're the same thing. [Unicode](http://web.archive.org/web/20130818043904/http:/www.unicode.org/) defines the following code points: - <cite>PRIME</cite> (U+2032): ′ - <cite>PRIME, DOUBLE</cite> (U+2033): ″ - <cite>PRIME, TRIPLE</cite> (U+2034): ‴ - <cite>PRIME, QUADRUPLE</cite> (U+2057): ⁗ (In case the above symbols aren't rendered properly on your browser, they're all angled.) There are other variants of the prime scattered throughout (reversed, modifier letter, and so on), but there is no separate code point for a <cite>foot</cite> symbol. The closest there is is <cite>FOOT, SQUARE</cite>; it's defined in the <cite>Miscellaneous Technical Range</cite> and it looks like a prime hanging inside an opening at the top of a square box. The [Unicode Character Names Index](http://web.archive.org/web/20130818043904/http:/www.unicode.org/charts/charindex.html) does have entries for <cite>feet</cite> and <cite>inches</cite>, but they are simple cross-references to the entries for <cite>PRIME</cite> and <cite>PRIME, DOUBLE</cite>, respectively. The [Wikipedia article on the prime symbol](http://web.archive.org/web/20130818043904/http:/en.wikipedia.org/wiki/Prime_(symbol)) supports this. Perhaps the confusion stems from the fact that on typewriters, feet and inches were represented using the same upright symbols used to represent apostrophes and quotation marks.
