In passing, it is considered a great faux pas to use lining (aka "capital") figures with small capitals. Either use full caps for OED, or old-style (aka "lowercase") figures, or small-cap height lining figures, which you'd probably have to make up. To be perfectly accurate, Heuristica is the old Adobe Utopia, which Adobe essentially made Open Source when Slimbach redrew it. It (Heuristica) is a bit different from the current for-sale Utopia...
