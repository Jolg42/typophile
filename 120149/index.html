If there is a font exactly like this, I don't recall seeing it. The lettering is an adaptation of a classic blackletter style called textura. The font with the closest basic letter-forms is Fette Gotish ![](http://web.archive.org/web/20141008024924im_/http:/typophile.com/files/FetteGotischAsArsenal_5474.gif) [https://www.myfonts.com/fonts/linotype/fette-gotisch/](http://web.archive.org/web/20141008024924/https:/www.myfonts.com/fonts/linotype/fette-gotisch/ "https://www.myfonts.com/fonts/linotype/fette-gotisch/") See also fonts like Unger Fraktur Fett ![](http://web.archive.org/web/20141008024924im_/http:/typophile.com/files/UngerFrakturFettAsArsenel_5707.gif) [http://www.myfonts.com/fonts/rmu/unger-fraktur/](http://web.archive.org/web/20141008024924/http:/www.myfonts.com/fonts/rmu/unger-fraktur/ "http://www.myfonts.com/fonts/rmu/unger-fraktur/") and, particularly for the \_s\_, Fette Fraktur ![](http://web.archive.org/web/20141008024924im_/http:/typophile.com/files/FetteFrakturasArsenal_6004.gif) [http://www.myfonts.com/fonts/linotype/fette-fraktur/](http://web.archive.org/web/20141008024924/http:/www.myfonts.com/fonts/linotype/fette-fraktur/ "http://www.myfonts.com/fonts/linotype/fette-fraktur/") Don
