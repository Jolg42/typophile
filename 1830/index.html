Typophile Forums Usability Suggestions

Administrators/Moderators/Users,

I think there are some things that could be done to make the forums a bit easier to use. Here are some issues I’ve found off the top of my head:

<ul>
<li>Place a “Start New Thread” button/link at the top of the page.</li>
<li>Increase the width of the “Post” box</li>
<li>Make “HTML code in message” object more robust. For example, <em> and <strong> tags are not supported (they’re actually more typographically/semantically correct) and one is unable to add a “title” attribute to anchor <a > elements.</li>
<li>ibid</li>
<li>Speed up the frickin Posting script. While previewing a post is relatively fast, posting takes FOREVER! My browser hangs for well over a minute and I’m on cable modem. This is surely a server/script issue.</li>
</ul>

Just thought I’d mention this stuff and welcome others’ suggestions so that we might further enhance the productivity of this already rich and thriving community.

Sorry if I posted this in the wrong place. Feel free to move it over to the "Non-Typographic" folder. I have another usability suggestion having to do with the navigation design of the forums. While it's nice to have a bread crumbs trail that shows where one is in context in the forums, it would be _really nice_ to have a persistant subnav that allows typophiles to jump from topic to topic witout having to click "Topics" in the global navbar. For example, say I'm in a thread in "General Discussions" and I want to go to the "Type Identification Board." Currently I have one of two options: 1. Click the back button twice to get to the top level. Then click "Type Identification Board." That's three clicks. 2. Click "Topics" and then click "Type Identification Board." That's two clicks. Why not set up a persistant subnav that links to the most popular topics, i.e., General Discussions | Design | Critique | Type Identification Board This would allow users to get there in (you guessed it) ONE click. Even better, let users customize the subnav to display the topics they visit most often. -t
