Anonymous @ 8 Jul 2006 — 8:28am
Adobe's existing OpenType fonts ALL encode every single glyph in the font, with the small caps, oldstyle figures, etcetera at standardized Unicode positions (around U+F6xx-F7xx). So there's no need to hack apart the font with special tools. You can access all those glyphs now. Mind you, Adobe is also abandoning this approach in new fonts moving forwards: glyphs without legitimate Unicodes, that are alternates or ligatures of standard characters, will be left unencoded (accessible by OpenType layout features). Anonymous @ 10 Jul 2006 — 5:44am
Preferred answer: Use only applications that support OpenType Layout features. Alternative answer: Word uses the Unicode codepoints. Any character with a Unicode codepoint can be entered into Word -- through standard system mechanisms such as an appropriate keyboard layout, the Character Map application (through the clipboard), and also by methods specific to Word, e.g. typing the four-letter hexadecimal code and pressing Alt+X, or through a VB macro. [Adam Twardoch](http://web.archive.org/web/20150307230611/http:/typophile.com/wiki/Adam%20Twardoch), in [FontLab forum](http://web.archive.org/web/20150307230611/http:/groups.msn.com/FontLab/general.msnw?action=get_message&mview=0&ID_Message=5986) N.B.: As Thomas said, Adobe will soon abandon the practice of using PUA codepoints, so the use of the method above is highly discouraged (even with fonts that contain PUAs nowadays).
