I believe what you need to do is add a 'Zapf' table to the font. This table includes a mapping between glyphs and all variants. See: [http://developer.apple.com/fonts/TTRefMan/RM06/Chap6Zapf.html](http://web.archive.org/web/20131020191038/http:/developer.apple.com/fonts/TTRefMan/RM06/Chap6Zapf.html)
