Anonymous @ 13.Apr.2006 11.53am
Fontlab’s (v4.5) `alias.dat` file inside the folder “Mapping” might not have the necessary entries. Use `T+commaaccent t+commaaccent S+commaaccent s+commaaccent` instead of `Tcommaaccent tcommaaccent Scommaaccent scommaaccent` Of course, you’ll need to have the necessary glyphs (T t S s commaaccent), before you use the command “Generate Glyphs...”

Anonymous @ 13.Apr.2006 12.25pm
Your glyph names and Unicode values are not entirely correct. You should use these: **Ș** — **Scommaaccent** (U+ **0218** ) **ș** — **scommaaccent** (U+ **0219** ) **Ţ** — **Tcommaaccent** (U+ **0162** ) **ţ** — **tcommaaccent** (U+ **0163** ) Some more info on the subject, from the Fontlab Forum: [[Tips / Glyph Naming] Glyph naming and encoding](http://web.archive.org/web/20071104015708/http:/groups.msn.com/FontLab/tipsandtricks.msnw?action=get_message&mview=0&ID_Message=3065)
