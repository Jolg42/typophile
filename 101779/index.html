Heather, in the 1920's typefaces did not work like today, where a set of computerised outlines can be moved from one medium to another with relative ease. A typeface then would merely be used for printing, practically all signs for instance would be hand-lettered. This logo was probably imput manually into the punch card for the Saurer machine (or whatever specific solution was used) and is not based on any specific typeface.
