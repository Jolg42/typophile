Yes, you would use GSUB lookup type 3 (one-to-one-of-many) so you would map from the default glyph to an enumerated set of possible alternates. See the [\<rand\> feature description](http://web.archive.org/web/20131108121643/http:/www.microsoft.com/typography/otspec/features_pt.htm#rand) in the OT spec for more details.
