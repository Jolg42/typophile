There are several sites that I have used as reference on period display typography. Most are bookmarked at home, but here are a few right now: Contemporary posters divided into categories: [AllPosters.com](http://web.archive.org/web/20090409084508/http:/www.allposters.com/) A great resource on [Advertising in America 1850-1920](http://web.archive.org/web/20090409084508/http:/scriptorium.lib.duke.edu/eaa/) No posters, but great for vintage ads in magazines [Ad\*Access](http://web.archive.org/web/20090409084508/http:/scriptorium.lib.duke.edu/adaccess/) If you browse through some of the galleries presented on LetterheadFonts.com, you can see contermporary designs using “antique-styled” typefaces. - [Main Gallery](http://web.archive.org/web/20090409084508/http:/www.letterheadfonts.com/gallery/) - [Portfolio 5](http://web.archive.org/web/20090409084508/http:/www.letterheadfonts.com/gallery/thumbnails.php?album=8)

BTW- you can always show them samples of Herb Lubalin’s work if you haven’t done so already. [Linotype - Lubalin](http://web.archive.org/web/20090409084508/http:/www.linotype.com/7-29-7-12333/worksandsamples.html) Also, a very nice compilation of typographic designs done by a student at UCLA. [Design for Print & Digital Media](http://web.archive.org/web/20090409084508/http:/users.design.ucla.edu/~cariesta/designhistory/) by Silvia Rigon Yet another link — not sure if you are plugged-in to the [Teaching Designers Network](http://web.archive.org/web/20090409084508/http:/tdn.freie-hochschule-freiburg.de/tdn.php), an international group of teaching designer which you can join.
