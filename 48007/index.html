XeTeX

Indices : Software : Design Applications : XeTeX

XeTeX is a document preparation system based on the TeX typesetting program and works with both LaTeX and ConTeXt. It is created by Jonathan Kew of SIL to be used with Unicode, currently it supports OpenType and AAT.

http://scripts.sil.org/xetex
