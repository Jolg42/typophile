I’m tying to make a small script with robafab far a multiple master Font.

For intance moving the “acute” accent inside “oacute”.
This is the script:
____________

g.components[1].move((-100,-100))

As far as I know, RoboFab is not able to deal with individual instances in a multiple master file. You might be able to achieve your goal by using FontLab’s native Python implementation instead. Otherwise, why not use anchors for placing accents? If done correctly it will save you the hassle of dealing with individual accented glyphs. -Paul van der Laan [www.type-invaders.com](http://web.archive.org/web/20140809070157/http:/www.type-invaders.com/ "www.type-invaders.com")
