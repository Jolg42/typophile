1. I don't think there are any specific rules for creating any kind of logo. 2. It would be quite challenging to create a 2-color version of that logo. There is lots of overlapping and transparency. 3. Illustrator, Inkscape, etc. would be your best bet. 4. This logo is really organic so I don't think a grid would help. I usually start out with pencil/paper... Hope that helps, Peter
