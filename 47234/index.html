Hey guys, I’m currently working on a project in which we need a calligrapher to write us a small text. The text is to written in a style somewhow similar to this one: http://www.veer.com/products/typedetail.aspx?image=PTT0000041#specimen

If you live or work in Barcelona and you are interested on this project, please contact me via Typophile or for this e-mail: nuno AT estudipuk DOT com

So Here is the Brief:

  • We need a nice text for something close to 500 characters for an invitation.
  • The style of the text we need is similar to:
    this one: http://www.veer.com/products/typedetail.aspx?image=PTT0000041#specimen
