Hi I reproduced part of your problem by changing the UPM value from 1000 to 10000 in Font Info Metrics and Dimensions panel. Could that be the problem? A typical value is 1000. Changing UPM makes the glyphs larger or smaller. No need to redesign the font. Tools/ Action.../ Contour/Scale with checking the scale metrics and proportional scale boxes checked. This can change the size of any selected glyph. Use a copy of your font to experiment on. Change UPM. Select the H and g glyphs (typical ascender and descender) and apply the scaling Action. Quick Test HgHgHg. If OK apply to entire font by checking the box bottom left of the Scale panel in Action. Make sure you use copies of the font and apply Ctrl Z to revert while experimenting. Good luck hope this solves it. Vladimir
