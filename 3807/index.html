Is Dutch ij ligature "atomic?"

I have a question for experts in Dutch language typography:

Anonymous @ 26.Mar.2004 11.18am
see [http://rudhar.com/lingtics/nlij\_en.htm](http://web.archive.org/web/20081204124241/http:/rudhar.com/lingtics/nlij_en.htm) for a discussion. The status of this letter is not well described. I'd like to add that the main reason I see why it is not much used, is because most type writers (and most computer keyboards) do not support it or through a difficult key sequence. Neither the upper case nor the lower case character is present in iso-8859-1, the character set we're supposed to be happy with in the Netherlands :-) Most people simply type ij, but this poses a problem in sorting.
