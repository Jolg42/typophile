Futura 'u' as alternate 'n'?

I am working on a logo(type), I’m using Futura Medium for this, all lower case.

The name has a ‘u’ and an ’n’, so during sketching I tried to rotate the ‘u’ 180 degrees and use that as an ’n’, less clutter because the ’n’ has this slightly ‘ascending’ stem on the left while the ‘u’ is like an upper case ‘U’.

Now this looks good imo, only thing… since there’s also an ‘a’ in the name, the ‘a’ would be the only character left with a slightly ‘descending’ and ‘ascending’ stem (right).

Is this weird? being inconsistant?

I mean the original font seems to be inconsistent too because the ‘u’ looks like an upper case ‘U’ still I’m not sure if I can leave the ‘a’ as is.

Anonymous @ 5 Feb 2013 — 1:41pm
If you want the "a" (like John's) to be less like an "o" you give it a hard top-right. Or you could make the "a" from a "u" rotated 90 degrees clockwise, then close the right side with a stem. BTW: - An "n" made from a flipped "u" will appear slightly narrower than the "u" (optical illusion) so you probably want to compensate for that. - Make sure you don't end up too close to this: [http://unum.newshq.businesswire.com/sites/unum.newshq.businesswire.com/f...](http://web.archive.org/web/20130923044924/http:/unum.newshq.businesswire.com/sites/unum.newshq.businesswire.com/files/logo/image/UnumBW.jpg "http://unum.newshq.businesswire.com/sites/unum.newshq.businesswire.com/files/logo/image/UnumBW.jpg") - What are the other letters in the name?
