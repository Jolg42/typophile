If you really want to do it “numerically” then you need to use Meter tool to find center of ’O’ and bar with guidelines (drag meter tool with right mouse button and select “create guideline at 50%” command in menu) then measure distance between these new guidelines and apply shift command from transformations panel to move the bar. However, it is much faster to do by eye, using Free transform tool.
