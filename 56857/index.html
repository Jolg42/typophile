But certainly some sort of space is gonna work better in the long run than none at all. Consider whether any of the notes will run to more than one line: are you going to do a hanging indent? If yes, that would support the space. Might there ever be two footnotes on one page? Asterisk & dagger aren't _necessarily_ going to have the same width so some tab-based space would then make sense to line up the text of both notes.
