Mac Type 1 fonts to Windows True Type

I’m not sure if this topic has been addressed already and I apologize if it’s a repeat issue, but I am currently working for a textbook publisher who’s now working a paperless workflow. We are currently using InDesign/InCopy on a server-based client with files generated outside the company (our studio) in InDesign using Mac Type 1 fonts. Our PDFs are generated through a PC server that we cannot change to an X-Serve at the moment. We have converted the fonts using TransType Pro 3.0.2 to Windows True Type as well Windows Open Type in hopes to find a medium for the cross-platforms to see the fonts in the files. Currently, when a file is opened on a Windows machine, it states the fonts are missing. Is there a way to have InDesign PC recognize the TTF or OTF versions of the Mac Type 1 fonts in the file?

Any and all insight you can provide is greatly appreciated.

~Saritza

Saritza: When I wrote ’font formats’ I was referring to the trio: TrueType, Type1 and OpenType. Notice that I didn’t make any remarks to PC or Mac (although the font files might not be interchangeable between both platforms, in some cases). So, what I would suggest is: decide which font format you want/can use (TT, T1 or OT), and then generate the font files, in that format, for both platforms. I believe that, once you have the same font (same format, but not necessarily the same files) installed in both platforms, PC and Mac, InDesign will not alert that the fonts are missing. Notes: 1. If you decide to go OT, the same files can be used in both platforms. 2. If you decide to go TT, you just need to generate the files for the PC (extension .ttf). These can then be used on the Mac (only OS X). 3. If you decide to go T1, that’s probably not the best choice, as the format has been phased out » [Read about it](http://web.archive.org/web/20071121102028/http:/blogs.adobe.com/typblography/2005/10/phasing_out_typ.html) Miguel
