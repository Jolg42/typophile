I believe the technical term is "radial gradient". There's a few different ways to make it. (assuming photoshop) -With the gradient tool. Select the gradient tool, then click the radial icon on the options bar. -With a layer style. Go to the "gradient overlay" tab and select the radial option. -With a fill layer. On the menu bar: Layer \> New Fill Layer \> Gradient... \> Click OK \> select radial

Anonymous @ 1 Aug 2009 — 10:49am
Start with a light gray layer. Make a new layer on top and make a large, circular feather edge brush (0 hardness). Set your foreground color to white, then just locate where you want the center of the light to be and click once. To get an even more gradual blend, you can use multiple layers, stepping down the size of the brush on each layer while going from light gray to white.
