Anonymous @ Thu, 2004-04-08 22:21
I think you were right about Tasse Marc, because it does have an alternate N like this, and an alternate rounded A. You can see the N and A [here](http://web.archive.org/web/20050518124543/http:/www.fontbureau.com/fonts/font_frames.tpl?cart=10663172097593320&fontname=Tasse) in the words "COMMUNITY OUTRAGED". It is shown more clearly in the Font Bureau Type Specimens book. While Solex has an S like this, it has neither the N nor the A. Of course, this has been slanted graphically, since Tasse has no oblique face.
Anonymous @ Fri, 2004-04-09 05:46
Both Tasse and Solex were created long after this movie was released. The inspiration for both of these was Steile Futura/Topic (both are names of the same Bauer foundry face) which had these alternate characters in the roman styles. It appears that the alternate characters were not included in the existing dital versions. Interesting that they used a face released in the mid-fifties for a film set 20 years earlier.
