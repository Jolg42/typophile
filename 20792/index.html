I'm not sure of the difference. While optical kerning may perhaps be a handy tool for large bodies of text, for display type (and wherever possible) one should always manually kern. I guess metric kerning would be based on the kerning info from the font file, where as optical is an approximation/adjustment based on the visual character. Still never going to be as good as adjusting by eye. ---------- **Paul Ducco** Solid Creative [Communication Design, Melbourne](http://web.archive.org/web/20131106213657/http:/www.solid-creative.com/)
