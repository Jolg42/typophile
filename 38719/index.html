Your wish is understood, I think.&nbsp;&nbsp;;-)&nbsp;&nbsp;If the weights/styles are compatible (in terms of both spacing and kerning) then it'd be better to space/kern one, and only in a second step copy values to the other master as described above, to check and correct values where necessary. If you manage to keep them 1:1 compatible, then only one style actually needs kerning values: generate the kern feature (with FLS' "Update kern feature" or the AFDKO2 script) and copy/paste it to the other fonts. If you use AFDKO2 to generate fonts, you wouldn't even need to do this but just refer to a common kerning file. So kerning values need not be present in all masters. But it is most unlikely that this would work.
