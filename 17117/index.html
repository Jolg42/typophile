Pieter, here’s what I would do... Create classes for your numerals like this: @class\_0 = [zero zero.OP]; @class\_1 = [one one.OP]; @class\_2 = [two two.OP]; @class\_3 = [three three.OP]; @class\_4 = [four four.OP]; @class\_5 = [five five.OP]; @class\_6 = [six six.OP]; @class\_7 = [seven seven.OP]; @class\_8 = [eight eight.OP]; @class\_9 = [nine nine.OP];
Anonymous @ 6.Jan.2006 9.32am
Arse... My post got bust up... Also add a class for the slashes: @class\_slash = [slash fraction];
Anonymous @ 6.Jan.2006 9.32am
Then your frac will look like this, (also incorporating the perthousand and percent subs Mr Connare suggested): feature frac { # Fractions # Latin sub @class\_0 @class\_slash @class\_0 @class\_0 by perthousand; sub @class\_0 @class\_slash @class\_0 by percent; sub @class\_1 @class\_slash @class\_4 by onequarter; sub @class\_1 @class\_slash @class\_2 by onehalf; sub @class\_3 @class\_slash @class\_4 by threequarters; } frac;
