I think it has a lot of potential. It has a wonderful textural presence. I especially like the way the letters start to interact with each other. It needs more work, but has a start it good. It had some feeling of a script, without being a script typeface. The weights need to be more normalized and the addition of numerous ligatures could make it much more smooth and pleasing to view. shu
