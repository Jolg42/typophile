The problem with using already built sets of classes is that one set will not work with all fonts. It’s not that hard to build a set from scratch and you are guaranteed that it will be optimized for the font you are working on. I don’t use Fontographer anymore, but the principle is the same for any font editor. I start out by analyzing all my glyphs, sorting them into groups with similar right or left sides. This becomes the basis for my kerning classes. Keep in mind that you don’t necessarily want to group accented glyphs with their unaccented counterparts. Also keep in mind that some character combinations may never come up in normal use. Yes, it can be a bit tedious, but there isn’t really any short cut that works better than thorough planning and methodical follow-through. With some people, it helps to have music on. I like to listen to audio books or talk radio.
