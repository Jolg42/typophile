It is indeed custom. Drawn by [Jon Gray](http://web.archive.org/web/20120101083414/http:/covers.fwis.com/everything_is_illuminated) and digitized by FontShop I believe. The actual name is HP PSG. The text that reads "The Computer is Personal Again" is actually an official logo lockup so it is was made separately from the typeface.
