Make sure you'll do the following: - Download the latest version from robofab.org (Robofab + FontTools + DialogKit) - After unzipping, place the RoboFab folder somewhere on your harddrive. I've put mine in my applications folder - Run install\_zip.py - Copy \*only\* the folder named 'Scripts' to your FontLab macro folder If you move the folder with the Robofab data to another location you need to run the install script again. Hope this helps. -Paul [www.type-invaders.com](http://web.archive.org/web/20120225213446/http:/www.type-invaders.com/ "www.type-invaders.com")
