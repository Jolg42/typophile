When viewing the PDF in Acrobat, check to see if you have "smooth line art" checked in your display prefs settings. This will help reduce jaggies. Also, you can zoom in lots to see if things get any more jagged. I expect that the vector illustration is still vector, so you're probably fine. BTW, QuarkXPress has added high res preview capability in QXP 6, although it is not as flexible as InDesign's options. But it sounds like this is a question of what's in the PDF, not how it shows up in QXP. Regards, T
