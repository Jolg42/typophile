_Is it really needed?_ Yes, if you consider that the previous version of Zapfino only had AAT features and not OT features. Zapfino Extra's features work in InDesign; the older Zapfino had to be used manually. OT features mean that it can be used as intended in a professional app like InDesign and not just an OS utility like TextEdit. Make sense?
