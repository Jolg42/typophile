Sorted it. It was in TOOLS \> ACTION SET \> All glyphs in Font (drop menu) \> Available Actions \> Contours \> Shift \> Click the -\> arrow to add to the right side menu \> Horizontal Shift - Type 8 \> Vertical Shift -Type 0. Then RUN :)
