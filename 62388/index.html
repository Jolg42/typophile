UFO is an open font format for interchanging font data between different font tools. You need to install RoboFab to use it. Among other things, it adds Python scripts to FontLab that allow it to read and write to the UFO format. You can get it here: [http://robofab.org/](http://web.archive.org/web/20100203110550/http:/robofab.org/ "http://robofab.org/")
