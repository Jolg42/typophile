Hi Michele, this uses RoboFab and calls a "Merge Contour" command to _clean_ the glyph. Optionally the script can color the glyph instead of calling the Merge Contour so you can edit the contour by yourself. ` #FLM: Sanitize BCP # scriptype - Paolo Mazzetti - 2009 from robofab.world import CurrentGlyph from FL import *` g = CurrentGlyph() for contour in g: try: for p in contour.bPoints: if p.bcpIn == p.bcpOut and p.bcpIn == (0,0): fl.CallCommand(fl\_cmd.ActionRemoveOverlap) #g.mark = 1 except: pass g.update() (Indentation won't probably make it) Cheers!
