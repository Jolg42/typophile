The Euro symbol is an abomination which shouldn't be used "as is" in text setting -- actually in _any_ setting. Use the euro symbol provided with the typeface you are using. The dreadful official Euro symbol can be found in [Adobe](http://web.archive.org/web/20111231071112/http:/typophile.com/wiki/Adobe)'s Euro Sans Regular which you can [download for free](http://web.archive.org/web/20111231071112/http:/store.adobe.com/support/downloads/product.jsp?product=48&platform=Macintosh).
