Anonymous @ 20.Mar.2009 6.06pm
First, a plea to keep [publishers and retailers](http://web.archive.org/web/20090326045853/http:/typographica.org/001157.php) separate in this discussion. [Emigre](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/Emigre) is a publisher, [MyFonts](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/MyFonts) is a retailer. [FontFont](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/FontFont) is a publisher, [FontShop](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/FontShop) is a retailer. If Hrant’s question is about publishers (AKA foundries) then there are very few that _don’t_ require exclusivity. There are always exceptions like ITC Franklin (an agreement between two publishers) and Eidetic Neo (a revision of an existing typeface submitted to another foundry). If Hrant’s question is about retailers (AKA resellers), there are very few that _do_ require exclusivity. Of course, some, like [FontShop](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/FontShop) and [Veer](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/Veer) do offer extra promotion or a special contract in exchange for exclusivity. Hybrid libraries include [T-26](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/T-26) and [Umbrella](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/Umbrella) (a [Veer](http://web.archive.org/web/20090326045853/http:/typophile.com/wiki/Veer) label) which include original fonts but also those that are published by other foundries.
