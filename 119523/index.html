The key to this lettering is the "gaspipe" or "stovepipe" corners. Start with a font with about the right height to width ratio and similar weight that has fairly tight curves outside AND inside, such as Ryoichi Tsunekawa's Design System A 700 ![](http://web.archive.org/web/20141017230419im_/http:/typophile.com/files/DesignSystemA700InUse1_6471.gif) ![](http://web.archive.org/web/20141017230419im_/http:/typophile.com/files/DesignSystemA700InUse2_5322.gif) ![](http://web.archive.org/web/20141017230419im_/http:/typophile.com/files/DesignSystemA700InUse3_5194.gif) ![](http://web.archive.org/web/20141017230419im_/http:/typophile.com/files/DesignSystemA700InUse4_3549.gif) ![](http://web.archive.org/web/20141017230419im_/http:/typophile.com/files/DesignSystemA700InUse5_6690.gif) [http://www.myfonts.com/fonts/flat-it/design-system/](http://web.archive.org/web/20141017230419/http:/www.myfonts.com/fonts/flat-it/design-system/ "http://www.myfonts.com/fonts/flat-it/design-system/") Clip and paste stovepipe elbows as required. Note the final row. These are the glyphs \_3\_, \_4\_ and \_l\_. For \_E\_ you could start by flipping \_3\_. For \_Y\_ you could start with \_4\_. For \_I\_ you could start with \_l\_. For \_N\_ ignore the round-top version and make a simple straight line \_N\_. Only the lhs of \_A\_ will take some curve-bending. Don

Anonymous @ 16 Sep 2014 — 11:07am
I mentioned Ryoichi Tsunekawa's Design System A 700 in a previous post and suggested a recipe for using it's corners to make stovepipe elbows to approximate the letters. Unfortunately the result is very approximate. The curves are too gradual and the weight is too light. I created my own stovepipe elbows from scratch and constructed these letters and the rest of an alphabet based on my conjecture as to what I thought might work with this concept. I have no idea how the the designer of the Knopf cover would have made the rest of the alphabet. So here is a Tsar Poutine alphabet in use ![](http://web.archive.org/web/20141017230419im_/http:/typophile.com/files/TTSS_SM2_6621.jpg) The picture of poutine was contributed by Jonathunder to Wikipedia [http://en.wikipedia.org/wiki/Poutine#mediaviewer/File:Poutine.JPG](http://web.archive.org/web/20141017230419/http:/en.wikipedia.org/wiki/Poutine#mediaviewer/File:Poutine.JPG "http://en.wikipedia.org/wiki/Poutine#mediaviewer/File:Poutine.JPG") The letters might be hard to digest and are definitely not part of a healthy diet. I might release Tsar Poutine as a font someday, but it does not seem like a very remunerative project. Don
