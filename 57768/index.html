The general conversion is point size \* resolution (your OS rasterizer screen resolution) / 72 = PPEM so this would mean your screen rasterizer is at 96 pixel per inch DPI. 16pt\*96/72 = 21.33 or 21 PPEM 12pt\*96/72= 16ppem etc. ![](http://web.archive.org/web/20131022021644im_/http:/typophile.com/files/screen_4181.jpg)

Rudy, the formula that Vincent has given above is in the FontLab Studio 5 user's manual in the first section ("Font Scaling, PPM") of chapter 9 ("Hinting"). I do recommend reading the FontLab Studio manual since it really includes some useful information about font development :) Please note that 96 is not always the default DPI size on Windows. Some notebook manufacturers pre-install Windows with the "Large fonts" (120 DPI) setting, and of course some users have the choice to set a yet different Custom DPI. I used to work on a 133 DPI setting for quite some time on my Dell notebook (which had a 1600×1200 15 inch screen so the pixels really had a physical resolution of 133 DPI, and the default 96 DPI setting rendered type so small that it was unreadable).
