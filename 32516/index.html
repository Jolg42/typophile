Both will be OpenType, but the 'Pro' version usually contains Central European characters on top of the standard set. So if you need Central European characters I would go for the Pro version. 'FF Meta OT 1' could've easily be called 'FF Meta Std 1'. Hope this helps.

The trouble is that every foundry has its own definition of "Pro". For FontFont it means additional language support -- CE, as Vincent said, but sometimes Greek and Cyrillic as well. You can check the PDFs on any OT font page at [FontShop](http://web.archive.org/web/20141027073959/http:/www.fontshop.com/index.cfm?fuseaction=verity.search&searchstr=FF%20Meta) to see what's included. The [FF OT Collection brochure](http://web.archive.org/web/20141027073959/http:/www.fontshop.com/virtual/newsletters/nov2006_b/FF-OpenType-Library-2.5.pdf) includes a handy matrix of language encodings.
