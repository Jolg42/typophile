Number of bars on a yen

Is it OK for a yen symbol just to have one bar? What about a Euro?

I have never seen the Japanese yen symbol written with just one bar. But I happen to know that the Latinized symbol for the Chinese renminbi, which is theoretically identical to the Japanese yen symbol (it shares the same Unicode code point), is more frequently written as a Y with a single crossbar. So you want to watch the context. A similar letter apparently appears in [Kazakh Cyrillic](http://web.archive.org/web/20101029193315/http:/en.wikipedia.org/wiki/%D2%B0). As for the Euro symbol, I doubt it would be recognizable with just one bar--it would look too much like the Ukrainian Ye to me in any event.

Anonymous @
The Euro was first build in 1974 to become a logo for the European Parlament. They didn't want the proposal and archived it. When the idea came up to produce a pan-European currency they remind of the proposal by Arthur Eisenmenger, took the logo and used it as the character for the Euro. Guide for a correct Euro-Sign: ![](http://web.archive.org/web/20101029193315im_/http:/typophile.com/files/guter_euro.gif) 1. affinity with the other currency signs 2. a little bit smaller and thinner than capitals 3. resemble more a lowercase c than an uppercase C 4. demands the same room as the numerics 5. crosses have sufficient distance 6. contrast, greytone, serifs… like in the main font more about it: [http://www.hitext.de/euro/euro.html](http://web.archive.org/web/20101029193315/http:/www.hitext.de/euro/euro.html "http://www.hitext.de/euro/euro.html") (german) Greetings: Steven
