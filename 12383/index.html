Adobe Dimensions would have been my first choice for this type of project, unfortunately Adobe have discontinued it and built its features in Illustrator CS which I haven’t used so much but is basically similar, if you are comfortable with Illustrator and don’t want a completely “lifelike” rendering I would try it first. For more full-on 3d software try Amapi, Bryce and Carrara which you can see here [http://www.eovia.com/](http://web.archive.org/web/20051122170136/http:/www.eovia.com/) but prepare yourself for a learning curve. Either way you will wish your computer was faster/more powerful. Tim
