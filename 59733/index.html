Anonymous @
I think I found the problem. I'm assuming that you're generating the PFA file from FontLab Studio (v5.0.4), yes? When the font's UPM value is different from 1000, FontLab Studio generates the PFA file with incorrect FontBBox values. The FontBBox values are correctly displayed in the "Key dimensions" pane of the Font Info dialog; but the values in the generated font will be different. ![](http://web.archive.org/web/20100203105014im_/http:/typophile.com/files/PFA_FBBox_3442.png) For quick workaround, just open the PFA file in a text editor and edit the FontBBox values to match what's displayed by the Font Info. BTW, CompareFamily quickly pointed me to the reason of the problem. **Single Face Test 15** (Warn if Font BBox x/y coordinates are improbable, or differ between head table and CFF) output the following message: **The font bounding box in the hhea table '(-322, -512, 2306, 1798)' differs from that in the CFF table '[-157, -250, 1126, 878]'.**
