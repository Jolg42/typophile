With all the squared techno fonts out there you'd think this should be easy to match, but the closest resemblance I found, even searching freeware sites, was [ITC Bolt](http://web.archive.org/web/20111222215550/http:/www.myfonts.com/fonts/linotype/itc-bolt/), which has squared counters and the wrong stroke width, or [Jay Gothic Extra Bold](http://web.archive.org/web/20111222215550/http:/www.myfonts.com/fonts/urw/jay-gothic/), which would need to be flattened/widened and otherwise massaged. This leads me to think that it is possibly a custom lettering job. - Mike Yanega
