Anonymous @ 27 Feb 2009 — 2:31pm
It is surprising that advertising people do not know nor care that the simpler the html stuff of a website, the more hits will result. I looked at the html internals of this "Is anyone else getting poor results..." thread, and it became clear for me why the Google results are so poor. For instance, this tiny thread alone has 30 picture links, a big css file, several php files, several js files and other stuff. Google's crawler would need too many seconds to evaluate this tiny thread, considering that Google tries to evaluate all websites of the entire world. The consequence is that Google simply skips many websites. The simpler the html stuff, the better for the Google crawler. For instance, my website has the simplest html imaginable (no css, no php, no js, etc.). The web design looks drab drab drab, but the hits are huge huge huge. Taking into consideration that my website deals with the rarest topics imaginable (e.g. the ancient Sanskrit language, which is studied by only very few people worldwide), the download hits for these very specialized files at my website are enormeous. In February, so far, for instance the pdf file cdrfonts.pdf was downloaded 1056 times, the txt file unicode.txt was download 817 times, and the "Sanskrit 2003" font sans2003.zip was downloaded 813 times. All this only at the [www.sanskritweb.NET](http://web.archive.org/web/20131023233238/http:/www.sanskritweb.net/ "www.sanskritweb.NET") site (I also run [www.sanskritweb.DE](http://web.archive.org/web/20131023233238/http:/www.sanskritweb.de/ "www.sanskritweb.DE") and [www.sanskritweb.ORG](http://web.archive.org/web/20131023233238/http:/www.sanskritweb.org/ "www.sanskritweb.ORG") as mirrow sites with separate download statistics). So, if you want to have many hits at the Typophile site brought about by Google search, then simplify the html stuff as much as possible so that it is easy for Google to evaluate your site.
