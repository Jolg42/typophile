How do you create the MM font? A.
Anonymous @ 9.Oct.2008 5.18pm
1. I have the light and bold weights open - these weights oulines have been checked with AFDKO’s Fix Contour order, sharp angles and start points and Outline check 2. With the light weight selected, Tools - Mask - Assign font Mask, and select the Bold weight. 3. Then, Tools - Multiple Master - Define New Axis, and select weight. 4. Then select all glyphs in the light weight, Tools - Multiple Master - Mask to Master and select Wt1
