There is a "Use them" section at [http://www.photofont.com/photofont/use/](http://web.archive.org/web/20110127213335/http:/www.photofont.com/photofont/use/ "http://www.photofont.com/photofont/use/") You can currently use photofonts in Adobe Photoshop and Adobe Illustrator using the free Photofont Start plugin.
