Anonymous @ 29 Aug 2008 — 1:55am
If Neutraface is the display face, a modern (didone) would be a good text complement. Or possibly a non-geo slab serif, e.g. Archer or Bodoni Egyptian. If Neutraface is the text, you could try matching a modern where the hairline corresponds to the weight of the text monoline. To see this effect, set up some 72 pt text in [Scotch Modern Display](http://web.archive.org/web/20150215161905/http:/www.shinntype.com/scotch.html) in the type tester, and put the window next to a showing of [Neutraface Light](http://web.archive.org/web/20150215161905/http:/www.houseind.com/index.php?page=showfont&id=18&subpage=viewfontspecimens) But really, any true ("optically sized") display face with lots of fine detail would complement the strong personality and sparkle of Neutraface text.
