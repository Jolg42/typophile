You could add a button on the first page so the user could choose to open the PDF full screen. If they don't click it, it stays in whatever view you defined in the document properties. Then on the last page, you'd put another button to drop out of full screen mode. See [http://typophile.com/node/40961](http://web.archive.org/web/20150225002848/http:/typophile.com/node/40961 "http://typophile.com/node/40961") for info on how to create buttons with actions.
