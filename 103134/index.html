Here is a grab of how Acrobat Reader 10.1.7 renders the font Ezra in the file `texmf/tex/makor2/refcard.pdf` of the makor2 TeX package (dated 2003) that I still have in my things. ![](http://web.archive.org/web/20131019150828im_/http:/typophile.com/files/ezradist_5387.png) The cause of the distortion was not, so far as I understand, "crappy curves". The elements in `BlueValues` were `-320 5 -76 707`, which just makes no sense. After changing `BlueValues`, the font was working without problem. Interestingly, Fontforge complains about the elements in BlueValues/OtherBlues of Bebas neue. Maybe the distortion on dafont also comes from there.
