This design has also been revived in a commercial font [Adadge Script JF](http://web.archive.org/web/20130914174423/http:/www.myfonts.com/fonts/jawfonts/adage-script-jf/) by Jason Walcott, which is perhaps more polished. AFAIK Lauren Script was produced as an original work previous to Adage Script and thus is in no way a rip of Adadge script. No info on the pre-digital original.
