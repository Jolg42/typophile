On Mac: Option+arrow changes the right sidebearing Cmd+arrow changes the left one On Win: Alt+arrow does not work Ctrl+arrow changes the left sidebearing To increase the right sidebearing you must increase the left one and then move the glyph to the left accordingly. Not sure if that was documented. :) Regards, Johnych

Now I've tested it on Windows: ctrl + alt + → = increase right sidebearing by 1 unit ctrl + alt + shift + → = increase right sidebearing by 10 units ctrl + alt + ← = decrease right sidebearing by 1 unit ctrl + alt + shift + ← = decrease right sidebearing by 10 units ctrl + → = increase left sidebearing by 1 unit ctrl + shift + → = increase left sidebearing by 10 units ctrl + ← = decrease left sidebearing by 1 unit ctrl + shift + ← = decrease left sidebearing by 10 units → = move outline to the right by 1 unit shift + → = move outline to the left by 10 units ← = move outline to the right by 1 unit shift + ← = move outline to the left by 10 units I'm using a German keyboard layout, but that shouldn't matter.
