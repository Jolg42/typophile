Matt, you don't say what kind of computer you're using. The standard encoding of text is different between Mac and Windows, so a text file is platform-specific (unless it's a Unicode text file, in which case, only a few applications can use it). Also, the standard character set included in a font is different between Mac and Windows, and depends on what language you're using. The character set above is missing some floating accents (common to both MacRoman and WinANSI), as well as some mac-specific and Windows-specific characters. Or maybe some of them just aren't displaying on my computer.... Incidentally, Adobe's new ISO-Adobe2 character set is a superset of the standard MacRoman and WinANSI character sets, plus the litre and estimated signs. Regards, T
