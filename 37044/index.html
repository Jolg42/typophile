Anonymous @ 12.Sep.2007 12.26pm
It’s easy. The source code on similicio.us references a css style sheet in this line: _link href=”sim.css” rel=”stylesheet” type=”text/css”_ So, simply add sim.css to the end of the url, like this: _http://similicio.us/sim.css_ Then, find the “h1” style attributed to the font you’re looking for. Viola! [Eileen Burke Graphic Design](http://web.archive.org/web/20071227152901/http:/www.eileenburke.org/)
