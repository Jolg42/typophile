the term that Adobe uses for these different styles is _[optical size](http://web.archive.org/web/20131017022631/http:/typophile.com/wiki/optical%20size)_. They are each intended to work optimally at different point sizes. Check this link: [http://www.adobe.com/type/topics/opticalsize.html](http://web.archive.org/web/20131017022631/http:/www.adobe.com/type/topics/opticalsize.html "http://www.adobe.com/type/topics/opticalsize.html")
