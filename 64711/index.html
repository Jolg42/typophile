One option is to fiddle around with the optical margin alignment (Type \> Story). If you need absolute control, you can insert tabs (1 at the beginning of each line) and set the tabulator to ‘align right’ (the text box itself has to be left-aligned). Now you can adjust the tab position for each line, if necessary. There are a lot of solutions. F
