Anonymous @ 16 Aug 2002 — 9:07am
Uh oh - Tiffany has become code happy. (Those bolds!) The 3 fonts... Font A - The design as it exists. Font B - Contains only the thick lines - the forms of the letters. Font C - Contains only the curly, scroll lines. The idea is to allow the user to seperately control the color of each element. For instance: if there was a legibility concern, the user could make the alphabetic forms a slightly darker color than the inside ornamentation. The different fonts would allow this change much quicker than tedius editing in Illustrator. If there is room for expiramentation with the inside curls, there is an opportunity for two more fonts: Font D - Could contain alternate (maybe longer), scroll lines. Font E - The full design with the alternate scroll lines.
