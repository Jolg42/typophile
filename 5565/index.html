Anonymous @ 14 July, 2004 - 2:55pm
[Dieter Steffmann](http://web.archive.org/web/20070318050348/http:/www.moorstation.org/typoasis/designers/steffmann/index.htm) digitized a set of 3 Parsons Bold fonts under the name Puritan. The set contains the base font as well as an Alternates and a Swash variant. None of these include the G in the Gracie image, but Puritan Regular contains that M, which the Alphabets version doesn't. Herr Steffmann digitized Parsons Heavy and, for some reason, allowed it to keep its name. This also includes an Alternates font. Finally, for completeness sake, there's an old Compuworks font called [Churchman](http://web.archive.org/web/20070318050348/http:/www.grsites.com/modperl/fontview.cgi?dir=c&fn=CW_CHRCH). This is Parsons Light. None of these fonts are terribly well made and the Compuworks font is missing some punctuation and all extended characters. They all look lousy on screen at even medium small sizes. I know how you all drool over Swash fonts, so here's Puritan Swash: ![](http://web.archive.org/web/20070318050348im_/http:/www.typophile.com/forums/messages/83/40711.gif)
