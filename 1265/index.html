I agree that TMs typically destract... \>\>You can register it if you want to, but there isn't much point unless you're a multi-million-dollar brand name. Partially disagree. Hrant, you can file all kinds of city, county and state stuff but [www.uspto.gov](http://web.archive.org/web/20080511225139/http:/www.uspto.gov/) is the place to go to file a national trademark. However, I'd check with a competent attorney. bj
