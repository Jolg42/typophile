As long as you stick to Freehand, you will not have enjoy an OpenType font fully, since it doesn't support more than 256 characters or any OpenType features. Why do you look for a TrueType version of Bickham? Windows XP will just work fine with any PostScript flavoured OpenType font, like Bickham Script (Pro). Without OpenType support you only get the basic latin character set, which includes everything you would normally expect to find in a font--caps, lowercase, numbers, punctuation, etc.--, but not the extra characters--alternates, swashes, Central European, etc.
Anonymous @
I'd like to point out a terminologic unclarity: "OpenType support" means different things. I usually say "OpenType Layout support" when I refer to the ability to handle the advanced typographic features. Freehand "supports" OpenType as a font format to the extent that it does support other font formats: the Roman codepage (256 character) and no advanced typography support. On the other hand, Adobe CS applications offer Unicode and OpenType Layout support. A.

ATM and the Adobe code that both Apple and Microsoft use for OTF (CFF) font support creates a standard kern table for older apps. The table is a subset of pairs derived from the kern feature, with all but western latin characters filtered out (more or less).
