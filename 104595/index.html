Anonymous @ 13 Jul 2013 — 12:32pm
FontLab can fill in the stem weights automatically if you click the 'auto stems' button in the hinting settings page of font info. However, you ideally need as few as possible, so I'd recommend measuring the lowercase stem widths (horizontal and vertical) with the ruler and putting these in. If uppercase has significantly different weights you can add those secondarily. It looks like you need to adjust your alignment zones a bit too; make sure they include all overshoots, and need to be entered in ascending numerical order (as you note, primary zones pull overshoots down, except the baseline and secondary zones pull overshoots up, like with the descenders).
