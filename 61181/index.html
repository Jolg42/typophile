Bearing in mind it is the same font with exactly the same properties (baseline shift, character styles, paragraph settings, etc.) I cant seem to understand the problem.

You are using an OpenType font with oldstyle numerals enabled (the top example). These are often used in running text, since they tend to blend in better. The bottom example would be called lining numerals, in which the numbers are all the same height. More and more typefaces nowadays include these two sets of numerals and more. Switching from one set to the other depends on the application you are using. If you are in InDesign, in the character palette click the flyout menu, then OpenType, and then (at the bottom) select the numeral style you would like. Read [this article](http://web.archive.org/web/20131105040926/http:/ilovetypography.com/2008/04/25/extreme-type-terminology-part-4) on I Love Typography for more information.
