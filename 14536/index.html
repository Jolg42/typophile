Maybe it’s a StuffIt archive. These usually have the extension “.sit”, but maybe the t got cut off. Try adding the t at the end. The Finder may ask if you are sure you want to do this—you do. The icon should turn into a StuffIt icon. You should be able to just double-click on it to un-stuff the font. If it’s not a StuffIt archive, I don’t know what it is.
