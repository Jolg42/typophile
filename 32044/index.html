Flash does not support OpenType advanced typographic features (ligature substitutions) at all. Basic ligatures (ff fi fl ffi ffl) have their own Unicode entries, but less conventional ligatures are either mapped to the PUA or [left unencoded](http://web.archive.org/web/20100203090725/http:/blogs.adobe.com/typblography/2006/05/eliminate_priva.html). In practice, this means: 1. Flash can not use unencoded glyphs. 2. It can use PUA-mapped glyphs (I think), but the original HTML page would render unreadable without the sIFR intervention. -- [omine.net](http://web.archive.org/web/20100203090725/http:/www.omine.net/)
