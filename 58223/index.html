Which feature for catchwords and catchwords.alt?

Howdy, I’ve got two styles of catchwords in my font and was wondering what feature (or combination thereof) to put them in.

Ornaments, Stylistic Set or Titling Alternates seem to make the most sense with titl having the broadest support.

However the only way to get them to work in photoshop is via dlig or salt. Is there a problem with having the functionality in both titl and salt?

Thinking of something like:

titl

sub A N D by AND.catch;
sub A n d by AND.catch;
sub a n d by AND.catch;
sub ampersand by AND.catch;

salt

sub AND.catch by AND.catch.alt;

Presumably you want to only perform these substitutions when the input string is not directly preceded or followed by another letter, otherwise you'll get the substitutions happening in words like ‘m_and_ible’. I don't think there is a problem with implementing the same substitution in more than one feature so long as there is a reasonable interpretation of the purpose of the features. I would be inclined to use dlig rather than salt, though.

Anonymous @
Yes, if you name your glyph A\_N\_D.catch then Acrobat will be able to find the glyph in a PDF\* if the user searches for the text "AND". If you use a name AND.catch, then Acrobat will "think" that it is just an unknown glyph. I recommend reading the Glyph Naming and Encoding chapter of the FontLab Studio 5 user's manual. \*) This only applies to some PDFs, depending on the way they were created. In some scenarios, Acrobat will still find AND.catch, but the name A\_N\_D.catch is safer and works in more occasions. Cheers, Adam
