It sounds like the Moonliner had a bit of a "space age" theme. If you haven't already, you might want to look into Googie architecture for more ideas. Some of the stuff might be too spacey, but it's from the right time period, so you might find some stuff that provides inspiration. [http://en.wikipedia.org/wiki/Googie\_architecture](http://web.archive.org/web/20120516110019/http:/en.wikipedia.org/wiki/Googie_architecture "http://en.wikipedia.org/wiki/Googie\_architecture") Clarendon would definitely be a good choice, but it's seen a big resurgence lately, so you might want to go in another direction to avoid looking like Ruby Tuesday or something like that.
