One of the font writers said; Gentium1021.zip which contains my modified versions of Gentium and Gentium Italic with the extra glyphs in the Private Use area. The TTF files have been renamed to avoid confusion with the originals, but the fontname is unchanged. To install them, backup your original Gentium fonts, uninstall them, and try these. They work fine in Wordpad, so they should be OK with other applications besides Word provided you have some means of actually typing them. In Wordpad, hold down the alter key and type the codepoints 57344 to 57348 and press space to insert the capitals. Hold down alter and type codepoints 57349 to 57353 to type the lowercase.
