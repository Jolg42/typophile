The font is [Le Asterix](http://web.archive.org/web/20070816151241/http:/www.myfonts.com/fonts/ef/le-asterix/). It has all upper case letters but the ones from the shifted keys have a different shape, given a more realistic simulation of real printing. This has a bold version called Le Obelisk, which I didn't see at MyFonts
